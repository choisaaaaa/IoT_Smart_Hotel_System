## 截图位置详解

### 【截图1】步骤1 - 前台办理入住
- **位置**: 前台端Web界面
- **内容要求**:
  - 显示入住表单（已填写）
  - 显示"确认入住"按钮
  - 显示"入住办理成功"提示

---

### 【截图2】步骤2 - MQTT权限下发
- **位置**: MQTT.fx 或 终端日志
- **内容要求**:
  ```
  主题: hotel/rooms/101/permissions
  消息: {
    "event": "guest_checkin",
    "room_id": 101,
    "card_id": "A1B2C3D4E5F6"
  }
  ```

---

### 【截图3】步骤3 - 客房终端激活
- **位置**: 终端日志 / 设备实物
- **内容要求**:
  ```
  收到权限消息
  执行欢迎模式:
    💡 灯光渐亮
    ❄️  空调开启 (24°C)
    🪟 窗帘打开
  状态已上报
  ```

---

### 【截图4】步骤4 - 客户端控制设备
- **位置**: 客户端APP界面
- **内容要求**:
  - 显示"我的房间"页面
  - 显示设备控制面板
  - 显示"灯光已关闭"状态
