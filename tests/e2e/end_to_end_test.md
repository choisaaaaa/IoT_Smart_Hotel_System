# 端到端场景测试

> **对应配图**: 8.5 端到端场景测试  
> **测试日期**: 2026-04-24  
> **测试人员**: 梁舒舒  
> **测试场景**: 客人入住全流程

---

## 测试概述

本测试验证从客人办理入住到客房设备控制的完整业务流程，展示"云边端"协同工作的能力。

**测试流程**:
```
前台办理入住 → 云端下发权限 → 客房终端激活 → 客户端控制设备
    (前台端)        (云端)          (边缘层)         (客户端)
```

---

## 测试步骤详解

### 步骤1: 前台办理入住

**操作界面**: 前台端Web

**操作步骤**:
1. 前台人员登录系统
2. 点击"办理入住"
3. 输入客人信息:
   - 姓名: 张三
   - 手机号: 13800138000
   - 身份证号: 110101199001011234
4. 选择房间: 101
5. 选择房型: 标准大床房
6. 设置入住日期: 2026-04-24
7. 设置离店日期: 2026-04-26
8. 点击"确认入住"

**预期结果**:
- 系统显示"入住办理成功"
- 生成房卡权限
- 房间状态变为"已入住"

**截图要点**:
- 入住表单填写完成
- 成功提示弹窗
- 房间状态变更

---

### 步骤2: 云端下发权限

**操作界面**: MQTT.fx 或 后端日志

**监控内容**:
```json
// 云端下发的MQTT消息
{
  "event": "guest_checkin",
  "room_id": 101,
  "card_id": "A1B2C3D4E5F6",
  "guest_name": "张三",
  "valid_from": "2026-04-24T14:00:00Z",
  "valid_until": "2026-04-26T12:00:00Z",
  "permissions": {
    "room_access": true,
    "device_control": true,
    "scene_control": true
  },
  "timestamp": "2026-04-24T14:00:00Z"
}
```

**预期结果**:
- MQTT消息成功发送到 `hotel/rooms/101/permissions`
- 客房终端收到权限配置
- 响应时间 < 1秒

**截图要点**:
- MQTT消息发布记录
- 消息内容详情
- 时间戳显示

---

### 步骤3: 客房终端激活

**操作界面**: 客房终端实物 / 终端日志

**激活流程**:
1. 客房终端接收到权限消息
2. 自动执行"欢迎模式":
   - 灯光渐亮
   - 空调开启并设置24°C
   - 窗帘打开
3. 上报设备状态到云端

**状态上报消息**:
```json
{
  "type": "status_report",
  "device_id": "room_terminal_101",
  "room_id": 101,
  "state": {
    "relay1": true,    // 灯光开启
    "relay2": false,   // 插座关闭
    "relay3": true,    // 空调开启
    "relay4": true,    // 窗帘打开
    "ac_temperature": 24
  },
  "scene": "welcome",
  "timestamp": "2026-04-24T14:00:05Z"
}
```

**预期结果**:
- 欢迎模式自动执行
- 设备状态正确上报
- 云端记录设备激活日志

**截图要点**:
- 终端日志显示欢迎模式执行
- 设备状态变化
- 实际上电效果（如有实物）

---

### 步骤4: 客户端控制设备

**操作界面**: 客户端Web / APP

**操作步骤**:
1. 客人打开客户端APP
2. 使用手机号登录
3. 进入"我的房间"
4. 看到房间101已激活
5. 点击"设备控制"
6. 执行以下操作:
   - 关闭灯光
   - 调节空调温度至26°C
   - 关闭窗帘

**控制指令**:
```json
// 客户端发送的控制指令
{
  "device_id": "room_101_light",
  "command": "turn_off",
  "user_id": "guest_001",
  "timestamp": "2026-04-24T14:05:00Z"
}
```

**预期结果**:
- 指令通过API发送到云端
- 云端转发到客房终端
- 设备执行动作
- 状态实时回传到客户端

**截图要点**:
- 客户端设备控制界面
- 操作按钮点击
- 设备状态实时更新
