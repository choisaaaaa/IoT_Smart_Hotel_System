# 慧宿智联测试代码 - 无脑使用教程

> 不用动脑，跟着步骤点就行

---

## 第一步：安装依赖（只需要做一次）

打开终端，复制粘贴下面这行：

```bash
cd tests && npm install
```

等待安装完成，看到一堆 `added xxx packages` 就是成功了。

---

## 第二步：运行测试（选你想展示的）

### 选项A：展示 API 接口测试（推荐，最直观）

```bash
cd tests && npm run test:api
```

**会看到什么：**
- 一堆绿色 ✓（表示测试通过）
- 响应时间（比如 45ms）
- 最后生成 HTML 报告

**报告位置：** `tests/reports/api_test_report.html`

双击打开，就是一个漂亮的网页报告，直接截图展示。

---

### 选项B：展示性能测试（展示 500 QPS）

先安装 k6：
- Windows: `winget install k6`
- Mac: `brew install k6`

然后运行：

```bash
cd tests && npm run test:perf:load
```

**会看到什么：**
- 实时显示请求数、响应时间
- 各种图表数据
- 最后显示 `✅ 所有测试通过`

---

### 选项C：展示后端单元测试覆盖率

```bash
cd backend/iot-hotel-backend && npm install && npm run test:coverage
```

**会看到什么：**
- 一个表格，显示 Statements、Branches、Functions、Lines 的百分比
- 绿色表示覆盖率高

---

### 选项D：生成统一测试报告（最省事）

先运行上面任意一种测试，然后：

```bash
cd tests && npm run report:generate
```

**会看到什么：**
- 生成 `tests/reports/unified_test_report.html`
- 打开后是一个完整的网页，包含：
  - 功能测试通过率 100%
  - 代码覆盖率
  - API 响应时间
  - 测试用例列表
  - Bug 修复状态

**直接打开这个 HTML 文件，就是完整的展示材料！**

## 常见问题（遇到问题看这里）

### Q1: 提示 "npm 不是内部命令"
**解决：** 先安装 Node.js，官网下载安装包一直点下一步

### Q2: 提示 "k6 不是内部命令"
**解决：** 先运行 `winget install k6` 安装 k6

### Q3: 测试运行很慢
**解决：** 正常现象，等一会就好，或者按 Ctrl+C 停止

### Q4: 有红色 × 出现
**解决：** 可能是后端服务没启动，先启动后端再运行测试

### Q5: 找不到报告文件
**解决：** 运行测试后，在 `tests/reports/` 文件夹里找

```bash
cd tests && npm install && npm run test:api && npm run report:generate
```
