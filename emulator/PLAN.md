## 1. 项目概述

### 1.1 项目目标

开发一套完整的硬件层仿真器系统，模拟智慧酒店物联网控制系统中的三个硬件终端：

| 终端 | 设备ID格式 | 主要功能 |
|------|-----------|---------|
| **前台管理端** | `front_desk_{编号}` | RFID开卡/验卡、广播呼叫、消音控制 |
| **楼控节点** | `floor_{编号}` | 环境监测、走廊灯光控制、消防报警 |
| **客房终端** | `room_{房间号}` | 设备控制、场景切换、语音通话、SOS报警 |

### 1.2 核心需求

- ✅ **三个独立的可执行程序**（.exe），分别对应三端硬件
- ✅ **完整的MQTT通信模拟**：连接、订阅、发布、心跳
- ✅ **所有实物操作仿真**：按钮、传感器、执行器的状态模拟
- ✅ **实时状态反馈**：设备状态变化实时上报
- ✅ **命令响应机制**：接收并执行后端下发的控制指令
- ✅ **可视化界面**：GUI展示设备状态和操作面板

## 2. 硬件层功能分析

基于现有硬件代码分析，三端硬件的功能如下：

### 2.1 前台管理端 (front_desk_terminal)

**硬件组件**:
- RC522 RFID读写器 - 房卡开卡/验卡
- RGB LED - 状态指示
- 蜂鸣器 - 声音反馈
- 2个物理按键 - 消音/广播

**MQTT主题**:
- 订阅: `hotel/device/command/front_desk/{device_id}`
- 发布: `hotel/device/status/front_desk/{device_id}`
- 发布: `hotel/device/command/result`
- 发布: `hotel/security/event`

**支持命令**:
| 命令 | 说明 |
|------|------|
| `issue_card` | 开卡（写入房间号到RFID卡） |
| `verify_card` | 验卡（读取RFID卡验证） |
| `swipe_card` | 刷卡（模拟刷卡动作） |

**本地事件**:
- 消音按钮 → 发送 `hangup_call` 到客房
- 广播按钮 → 发送 `incoming_call` 到客房

### 2.2 楼控节点 (floor_controller)

**硬件组件**:
- DHT11温湿度传感器
- 光敏传感器(LDR)
- MQ2烟雾传感器
- 继电器 - 走廊灯光控制
- 1个物理按键 - 消防报警

**MQTT主题**:
- 订阅: `hotel/device/command/floor/{device_id}`
- 发布: `hotel/device/status/floor/{device_id}`
- 发布: `hotel/device/data/{sensor_type}/{device_id}`
- 发布: `hotel/security/event`

**支持命令**:
| 命令 | 说明 |
|------|------|
| `light_on` | 开启走廊灯 |
| `light_off` | 关闭走廊灯 |
| `broadcast_start` | 启动广播 |
| `broadcast_stop` | 停止广播 |
| `floor_reset` | 楼控复位 |

**传感器上报**:
- 温度 (temperature) - 每30秒
- 湿度 (humidity) - 每30秒
- 光照 (light) - 每30秒

### 2.3 客房终端 (room_terminal)

**硬件组件**:
- OLED显示屏 - 状态显示
- RC522 RFID - 门禁刷卡
- 4路继电器 - 灯光/空调/窗帘/门锁
- DHT11传感器 - 环境监测
- RGB LED - 氛围灯
- 蜂鸣器 - 提示音
- 2个物理按键 - 场景切换/SOS
- 音频模块 - 语音通话

**MQTT主题**:
- 订阅: `hotel/device/command/room/{device_id}`
- 订阅: `hotel/ai/response/room/{room_id}`
- 发布: `hotel/device/status/room/{device_id}`
- 发布: `hotel/device/data/{sensor_type}/{device_id}`
- 发布: `hotel/device/command/result`
- 发布: `hotel/security/event`
- 发布: `hotel/ai/request/room/{room_id}`

**支持命令**:
| 命令 | 说明 |
|------|------|
| `light_on` / `light_off` | 主灯控制 |
| `air_on` / `air_off` | 空调控制 |
| `curtain_open` / `curtain_close` | 窗帘控制 |
| `door_unlock` / `door_lock` | 门锁控制（8秒自动回锁） |
| `incoming_call` / `hangup_call` | 语音通话 |
| `scene_welcome` / `scene_reading` | 场景切换 |
| `scene_night` / `scene_sleep` | 场景切换 |
| `scene_next` | 下一场景 |

**传感器上报**:
- 温度 - 每15秒
- 湿度 - 每15秒

## 8. 实现细节

### 8.1 MQTT消息格式

**设备上线状态**:
```json
{
  "device_id": "front_desk_01",
  "device_type": "front_desk",
  "status": "online",
  "firmware_version": "v1.1.0",
  "timestamp": "2026-04-21T10:00:00Z"
}
```

**心跳消息**:
```json
{
  "device_id": "front_desk_01",
  "status": "online",
  "battery_level": 100,
  "signal_strength": -50,
  "uptime": 3600,
  "memory_usage": 45,
  "timestamp": "2026-04-21T10:00:00Z"
}
```

**传感器数据**:
```json
{
  "device_id": "floor_03",
  "sensor_type": "temperature",
  "value": 25.5,
  "unit": "℃",
  "timestamp": "2026-04-21T10:00:00Z"
}
```

**控制指令**:
```json
{
  "command_id": 1001,
  "device_id": "room_301",
  "command_type": "light_on",
  "command_value": "{}",
  "created_by": "system",
  "timestamp": "2026-04-21T10:00:00Z"
}
```

**指令执行结果**:
```json
{
  "device_id": "room_301",
  "command_id": 1001,
  "command_type": "light_on",
  "status": "success",
  "result": "执行成功",
  "timestamp": "2026-04-21T10:00:00Z"
}
```

**安防事件**:
```json
{
  "device_id": "room_301",
  "event_type": "room_sos_pressed",
  "event_data": {"room_id": 301},
  "level": "critical",
  "timestamp": "2026-04-21T10:00:00Z"
}
```

## 9. 验收标准

### 9.1 功能验收

| 检查项 | 验收标准 |
|--------|---------|
| MQTT连接 | 能正常连接MQTT Broker，支持断线重连 |
| 心跳上报 | 各端按指定频率自动上报心跳 |
| 命令响应 | 能正确接收并执行所有支持的命令 |

## 10. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| MQTT连接不稳定 | 高 | 实现指数退避重连机制 |
| GUI卡顿 | 中 | 使用多线程，MQTT通信放后台 |
| 打包体积大 | 低 | 使用UPX压缩，精简依赖 |
| 配置复杂 | 低 | 提供默认配置，图形化配置界面 |
