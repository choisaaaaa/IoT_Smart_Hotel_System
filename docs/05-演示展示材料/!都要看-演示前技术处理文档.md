## 二、各模块演示前技术处理

### 2.1 硬件模块（负责人：向前）

#### 2.1.1 设备初始化检查
```
□ 所有传感器已正确连接到主控板
□ 主控板已烧录最新版固件程序
□ 设备已配置正确的WiFi连接信息
□ 设备已注册到MQTT服务器
□ 各传感器数据上报间隔设置合理（建议2-5秒）
□ 继电器控制逻辑测试通过
```

#### 2.1.2 演示场景预设
```
□ 场景1：客人入住 - 门锁开启、灯光自动亮起、空调开启
□ 场景2：环境调节 - 温湿度超标时自动调节空调/加湿器
□ 场景3：节能模式 - 无人检测时自动关闭灯光和空调
□ 场景4：远程控制 - 通过APP远程开关设备
```

#### 2.1.3 故障应急预案
- 准备备用主控板1套
- 准备备用传感器各1个
- 确保所有设备可快速替换

## 五、应急处理方案

### 5.1 硬件故障
| 故障现象 | 应急措施 |
|----------|----------|
| 设备无法启动 | 立即更换备用设备 |
| 传感器数据异常 | 重启设备或更换传感器 |
| 网络连接中断 | 切换至备用热点 |
| 继电器不响应 | 检查接线，必要时手动演示 |

### 5.2 软件故障
| 故障现象 | 应急措施 |
|----------|----------|
| 后端服务崩溃 | 快速重启服务，准备录屏备用 |
| APP闪退 | 重新安装或切换备用手机 |
| 数据库连接失败 | 检查连接配置，重启数据库服务 |
| 页面加载缓慢 | 清理缓存，准备离线截图备用 |

### 5.3 录制故障
| 故障现象 | 应急措施 |
|----------|----------|
| 录屏软件崩溃 | 切换备用录屏软件 |
| 声音录制失败 | 后期配音或使用文字说明 |
| 视频文件损坏 | 分段录制，确保每段完整 |
