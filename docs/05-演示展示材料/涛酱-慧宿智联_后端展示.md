## 一、 模块概述

> **演示负责人**：陈剑涛

### 3.2 API接口演示 - 1分钟

#### 3.2.1 认证接口
```http
POST /api/v1/auth/login
Content-Type: application/json

{
  "phone": "13800138000",
  "password": "******"
}
```

**响应**：
```json
{
  "success": true,
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "user": {
      "id": 1,
      "name": "管理员",
      "role": "admin"
    }
  },
  "message": "登录成功"
}
```

**展示点**：JWT无状态认证、角色区分

---

#### 3.2.2 房态更新接口
```http
PATCH /api/v1/rooms/801/status
Authorization: Bearer {token}
Content-Type: application/json

{
  "status": "occupied",
  "guest_name": "张三"
}
```

**响应**：
```json
{
  "success": true,
  "data": {
    "room_id": 801,
    "status": "occupied",
    "updated_at": "2026-04-24T10:30:00Z"
  },
  "message": "房态更新成功"
}
```

**展示点**：
- 数据库事务保证数据一致性
- MQTT消息同步通知硬件
- 响应时间 < 200ms

## 四、 技术亮点

### 4.1 安全机制
- **JWT认证**：无状态Token，支持黑名单刷新
- **RBAC权限**：角色基于访问控制（admin/manager/staff/guest）
- **接口限流**：15分钟内1000次请求限制
- **数据加密**：敏感字段AES加密存储

### 4.2 高可用设计
- **连接池管理**：MySQL连接池（limit: 10）
- **自动重连**：数据库断线自动重连机制
- **PM2守护**：进程崩溃自动重启
- **日志监控**：Winston分级日志记录

### 4.3 实时通信
- **MQTT QoS 1**：确保消息至少送达一次
- **设备影子**：Redis缓存设备最新状态
- **心跳检测**：设备5秒心跳，离线自动检测
