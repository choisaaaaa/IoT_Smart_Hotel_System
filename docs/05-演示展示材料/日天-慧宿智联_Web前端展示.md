# 慧宿智联·Web前端展示 (Web Frontend Gallery)

## 一、 模块概述

> **演示负责人**：钟昊  
> **演示时长**：4分钟  
> **核心目标**：展示Web管理端的完整功能，体现酒店运营管理的数字化、智能化能力。

本系统基于 **Vue 3 + Vite + Ant Design Vue + Pinia** 构建，采用响应式布局，包含**管理端**（酒店管理员）和**前台端**（前台员工）两套界面，确保不同角色均能获得流畅的操作体验。

## 三、 核心演示流程

### 3.1 管理端 - 数据可视化仪表盘 - 1分钟

**演示步骤**：
1. **登录管理端**
   - 展示登录页 → 进入Dashboard

2. **仪表盘概览**
   - **实时入住率**：饼图展示（空闲30%/在住60%/维修10%）
   - **今日营收**：¥12,580（实时更新）
   - **今日订单**：15个新订单
   - **设备在线率**：95%（28/30设备在线）

3. **趋势图表**
   - 近7天入住率曲线
   - 能耗统计柱状图
   - 收入趋势折线图

**展示点**：ECharts数据可视化、实时数据更新

---

### 3.2 前台端 - 房态沙盘与入住办理 - 1.5分钟

**演示步骤**：

#### 3.2.1 房态沙盘
- **网格化布局**：按楼层展示所有房间
- **色块标识**：
  - 🟢 绿色：空闲（802）
  - 🔴 红色：在住（801）
  - 🟡 黄色：待打扫
  - ⚫ 灰色：维修（803）
  - 🔵 蓝色：已预订

- **操作**：点击房间查看详情、切换房态

#### 3.2.2 今日预定清单
- 展示今日待入住订单列表
- 点击"办理入住" → 弹出入住对话框
- 输入住客信息 → 确认 → 房态自动变为"在住"
- 触发：MQTT通知硬件开启门锁

#### 3.2.3 退房办理
- 选择801房间 → 点击"办理退房"
- 展示账单明细 → 确认退房
- 房态自动变为"待打扫"

**展示点**：房态实时同步、业务流程自动化

---

### 3.3 IoT设备管控中心 - 1.5分钟

**演示步骤**：

#### 3.3.1 设备列表
- 展示所有接入设备：
  - 801-主控板：在线 ✅
  - 801-空调：在线 ✅
  - 801-灯光：在线 ✅
  - 803-主控板：离线 ❌

#### 3.3.2 远程控制演示
- 选择801房间 → 设备控制面板
- **灯光控制**：开关切换（观察硬件响应）
- **空调控制**：温度调节、模式切换
- **窗帘控制**：开合控制

#### 3.3.3 告警信息
- 展示设备告警列表：
  - 803房间主控板离线（10分钟前）
  - 201房间温度异常（28℃）
- 点击处理 → 标记为"已处理"

**展示点**：Web到硬件的实时控制、告警管理

## 五、 技术架构亮点

### 5.1 技术栈
- **框架**：Vue 3 + Composition API
- **构建工具**：Vite 5.x
- **UI组件库**：Ant Design Vue 4.x
- **状态管理**：Pinia
- **图表库**：ECharts 5.x
- **HTTP客户端**：Axios
- **实时通信**：MQTT over WebSocket

### 5.2 性能优化
- **路由懒加载**：按需加载页面组件
- **组件复用**：通用组件封装（设备控制器、房态卡片）
- **数据缓存**：Pinia状态持久化
- **响应式布局**：适配1280px-1920px屏幕

## 七、 应急处理

| 故障现象 | 应急措施 |
|----------|----------|
| 页面卡顿 | 刷新页面，预加载核心模块 |
| 数据不同步 | 点击刷新按钮，检查WebSocket连接 |
| 鉴权失败 | 使用备用账号登录 |
| 图表不显示 | 检查ECharts依赖，准备静态截图 |
