# 慧宿智联·后台管理系统展示 (Admin Management System Gallery)

## 一、 模块概述

> **负责人**：钟昊\
> **核心目标**：提供直观、高效的酒店运营管理平台，实现对房态、设备、能耗及用户权限的全方位管控。

本系统基于 **Vue 3 + Ant Design Vue + Pinia** 构建，采用响应式布局，确保管理人员在不同设备上均能获得流畅的操作体验。

***

## 二、 演示功能核心看板 (Core Dashboard)

### 2.1 仪表盘数据可视化 (Data Visualization)

- **实时入住率**：通过饼图动态展示当前全店房间状态（空闲、在住、维修、待扫）。
- **营收/订单统计**：展示当日预定量及实时营收金额。
- **设备在线状态**：实时统计各楼层 IoT 设备的在线率及告警数量。

### 2.2 房态沙盘与管理 (Room Management)

- **可视化沙盘**：通过网格化布局实时展示所有房间状态，支持按楼层、房型过滤。
- **业务联动操作**：演示办理入住、退房、一键报修及房态手动切换（CRUD 操作）。
- **房间详情**：查看对应房间的住客信息、历史订单及关联的硬件设备列表。

***

## 三、 IoT 设备管控中枢 (IoT Control Center)

### 3.1 设备管理与监控

- **设备列表**：展示所有接入的 ESP32 主控、传感器及执行器（灯光、空调等）的实时在线状态。
- **远程控制演示**：
  - **灯光/窗帘**：在后台界面点击开关，演示 MQTT 指令下发后的硬件秒级响应。
  - **环境调节**：设置温度阈值，演示温湿度超标时的自动控制逻辑。
- **告警信息流**：实时展示设备离线、传感器数值异常（如烟雾报警）的历史记录与处理状态。

### 3.2 报表与日志

- **操作审计日志**：记录管理人员对系统配置、设备控制的关键操作，确保安全可追溯。

## 五、 应急处理方案 (Emergency Plan)

- **页面卡顿**：演示前预加载所有核心模块，确保静态资源已完全缓存。
- **数据不同步**：若房态未实时更新，演示一键刷新功能，并通过后端日志定位 WebSocket/MQTT 连接状态。
- **鉴权失败**：准备备用管理员账号，防止因 Token 过期导致的登录中断。
