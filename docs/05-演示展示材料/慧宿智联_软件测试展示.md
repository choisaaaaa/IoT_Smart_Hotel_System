## 七、 性能测试报告 (Performance Report)

### 5.1 响应耗时
*   **API 平均响应**：< 150ms (本地环境) / < 300ms (远程数据库环境)。
*   **WebSocket 推送延迟**：< 50ms。
*   **AI 语义解析耗时**：GLM-4-Flash 平均生成时间 1.2s - 2.5s。

### 5.2 负载承受能力
*   **并发连接数**：支持 1000+ 同时在线心跳维持。
*   **吞吐量**：通过 Redis 缓存设备影子数据，显著降低了 MySQL 的 CPU 占用率，在 500 QPS 下系统无卡顿。
