# 慧宿智联·APP模块展示 (Mobile App Gallery)

## 一、 模块概述

> **演示负责人**：姚肇杰\
> **演示时长**：4分钟\
> **核心目标**：展示移动端APP的完整功能，体现住客从预订到入住再到客房控制的全流程体验。

本APP采用 **Flutter** 跨平台框架开发，具备原生级的流畅体验，完美适配 Android 与 iOS 系统，是住客与酒店智慧系统交互的核心入口。

***

## 二、 演示前准备

### 2.1 环境自检

```
□ 使用演示专用账号登录（避免隐私数据）

□ 手机屏幕清洁，网络连接至专用WiFi (IoT_Demo)
□ 录屏权限已开启
```

### 2.2 演示数据预设

| 房间号     | 状态      | 设备配置              | 演示重点           |
| :------ | :------ | :---------------- | :------------- |
| **801** | **已入住** | 完整配置（灯光、空调、窗帘、门锁） | 核心功能全流程控制、场景切换 |
| **802** | **空房**  | 待机状态              | 房态同步、预订流程      |

## 三、 核心演示流程

### 3.1 酒店搜索与预订 - 1分钟

**演示步骤**：

1. **首页搜索**
   - 展示目的地输入、日期选择、人数选择
   - 点击搜索，秒级返回酒店列表（Redis缓存加速）
2. **酒店详情**
   - 展示酒店全景图、设施标签、住客评价
   - 房型列表：标准间、豪华间、套房
3. **在线预订**
   - 选择房型 → 填写联系人信息 → 确认订单
   - 模拟支付流程（余额/微信）
   - 预订成功，订单进入"待入住"状态

**展示点**：流畅的预订体验、实时房态查询

***

### 3.2 在线入住办理 - 1分钟

**演示步骤**：

1. **我的订单**
   - 展示刚刚创建的订单
   - 点击"在线入住"
2. **获取房卡**
   - 审核通过，显示房间号801
   - 展示临时PIN码（用于门锁/取电）
   - 提示"到店即入住，无需前台排队"

**展示点**：无接触入住、身份安全验证

***

### 3.3 智慧客房控制 - 2分钟

**演示步骤**：

#### 3.3.1 房间总览

- 进入"我的房间" → 801房间
- 展示房间设备列表：
  - 主灯：开启/关闭
  - 空调：26℃ 制冷模式
  - 窗帘：已关闭
  - 门锁：已上锁

#### 3.3.2 设备精细控制

- **灯光控制**：开关切换、亮度滑动调节（0-100%）
- **空调控制**：模式切换（制冷/制热/送风）、温度调节（16-30℃）
- **窗帘控制**：开合百分比控制

**展示点**：控制响应速度 < 1秒，MQTT实时同步

#### 3.3.3 AI智慧管家

- 点击"AI管家"进入对话界面
- **语音指令演示**：
  - "打开空调并调至26度"
  - "关闭所有灯光"
  - "WiFi密码是多少？"
- **展示**：ASR语音识别 → 意图解析 → 设备控制/知识库问答

#### 3.3.4 场景模式切换

- **回家模式**：开灯→开空调→开窗帘
- **睡眠模式**：关灯→关窗帘→空调静音
- **离家模式**：关闭所有设备

**展示点**：一键场景联动，多设备协同

***

### 3.4 客房服务 - 快速展示

**演示步骤**：

1. **送物服务**
   - 选择物品：矿泉水、毛巾、拖鞋
   - 提交请求，查看配送进度
2. **一键报修**
   - 选择故障类型：空调不冷、灯不亮
   - 上传照片，提交工单
3. **呼叫前台**
   - 一键拨号/在线语音通话

***

## 四、 技术架构亮点

### 4.1 技术栈

- **框架**：Flutter 3.x
- **状态管理**：Riverpod
- **网络**：Dio + 拦截器（JWT自动刷新）
- **实时通信**：MQTT Client
- **本地存储**：Hive

### 4.2 性能指标

| 指标     | 数值                      |
| ------ | ----------------------- |
| 页面加载   | < 500ms                 |
| 设备控制响应 | < 1秒                    |
| MQTT延迟 | < 200ms                 |
| 包大小    | Android 15MB / iOS 25MB |
