# 慧宿智联·硬件模块展示 (Hardware Module Gallery)

## 一、 模块概述

> **演示负责人**：向前  
> **演示时长**：5分钟  
> **核心目标**：展示硬件系统的实际运行效果，演示从传感器采集到执行器控制的完整物联网链路。

本系统硬件核心采用 **ESP32-S3** 高性能SoC，通过 **MQTT** 协议实现与云端的双向实时通信，支撑起整个"云-边-端"架构的物理基础。

## 三、 核心演示场景

### 场景1：智慧入住 (Smart Check-in) - 1分钟
*   **触发**：前台办理入住（Web端操作）
*   **动作链**：
    1. 门锁自动开启（继电器触发）
    2. 客房灯光由暗转亮（渐变效果）
    3. 空调自动开启至26℃欢迎模式
*   **展示点**：云-边-端协同响应速度（<1秒）

### 场景2：环境智能调节 (Environmental Tuning) - 1分钟
*   **触发**：传感器监测数据超标
*   **动作链**：
    1. DHT11检测到温度>28℃ → 自动开启空调
    2. 光照传感器检测光照不足 → 自动开灯
    3. 数据实时上报至云端Dashboard
*   **展示点**：边缘计算自主决策能力

### 场景3：绿色节能模式 (Energy Saving) - 1分钟
*   **触发**：RD-03毫米波雷达检测房间无人（持续5分钟）
*   **动作链**：
    1. 自动关闭所有灯光
    2. 关闭插座电源
    3. 空调进入节能模式
*   **展示点**：毫米波雷达精准存在检测（呼吸级微动感知）

### 场景4：远程实时管控 (Remote Control) - 2分钟
*   **触发**：通过APP/Web下发控制指令
*   **动作链**：
    1. APP点击"睡眠模式"
    2. MQTT指令秒级下发至硬件
    3. 硬件执行：关灯→关窗帘→空调静音
    4. 执行状态实时回传至APP
*   **展示点**：双向通信可靠性、场景联动能力

## 四、 技术亮点展示

### 4.1 通信架构
```
APP/Web ──→ 云端服务器 ──→ MQTT Broker ──→ ESP32网关 ──→ 传感器/执行器
    ↑                                              ↓
    └──────────── 状态回传 ←───────────────────────┘
```
*   **协议**：MQTT over TCP
*   **延迟**：端到端 < 200ms
*   **QoS**：Level 1（至少一次送达）

### 4.2 传感器融合
| 传感器 | 数据类型 | 采样频率 | 应用场景 |
|--------|----------|----------|----------|
| DHT11 | 温湿度 | 5秒 | 环境调节 |
| 光照传感器 | 光照强度 | 1秒 | 自动照明 |
| RD-03雷达 | 人体存在 | 实时 | 节能/安防 |
| MQ-2 | 烟雾浓度 | 5秒 | 安全告警 |

### 4.3 执行器控制
*   **继电器**：4路隔离控制，支持灯光/窗帘/插座/空调
*   **门锁**：电磁锁驱动，支持刷卡/远程/机械钥匙
*   **红外**：学习模式控制传统空调/电视

## 五、 故障应急预案

| 故障现象 | 应急措施 |
|----------|----------|
| 设备掉线 | 检查电源与WiFi信号，准备备用主控板快速替换 |
| 传感器失效 | 备用传感器各1个随时待命，支持热插拔恢复 |
| 继电器卡死 | 检查驱动电路，必要时通过物理手动开关演示 |
| MQTT连接中断 | 设备自动重连，本地离线逻辑保障基础功能 |
