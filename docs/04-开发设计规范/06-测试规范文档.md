## 3. API测试方法

### 3.1 登录获取Token

```powershell
$r = Invoke-RestMethod -Uri 'http://localhost:3000/api/v1/auth/login' `
  -Method Post -ContentType 'application/json' `
  -Body '{"phone":"13900000005","password":"123123"}'
$token = $r.data.token
$h = @{Authorization="Bearer $token"}
```

### 3.2 创建预订+支付+入住全流程

```powershell
# 创建预订
$bk = '{"hotel_id":1,"room_id":18,"room_type":"standard","check_in_date":"2026-04-12","check_out_date":"2026-04-13","guest_name":"test","guest_phone":"13900000005","guest_count":1}'
$r1 = Invoke-RestMethod -Uri 'http://localhost:3000/api/v1/bookings' -Method Post -Body $bk -Headers $h -ContentType 'application/json'
$bid = $r1.data.id

# 创建支付
$pb = "{`"order_type`":`"booking`",`"order_id`":$bid,`"amount`":$($r1.data.total_price),`"payment_method`":`"balance`"}"
$r2 = Invoke-RestMethod -Uri 'http://localhost:3000/api/v1/payments' -Method Post -Body $pb -Headers $h -ContentType 'application/json'
$payId = $r2.data.id

# 确认支付
$r3 = Invoke-RestMethod -Uri "http://localhost:3000/api/v1/payments/$payId/pay" -Method Put -Headers $h

# 在线入住
$cb = '{"guest_phone":"13900000005","real_name":"test","id_type":"idcard","id_number":"123456789012345678"}'
$r4 = Invoke-RestMethod -Uri "http://localhost:3000/api/v1/bookings/$bid/checkin-online" -Method Post -Body $cb -Headers $h
```

### 3.3 数据库一致性验证SQL

```sql
-- 检查支付与预订hotel_id一致性
SELECT b.id, b.status, b.hotel_id, p.id as payment_id, p.status, p.hotel_id as payment_hotel_id
FROM bookings b
LEFT JOIN payments p ON p.order_type = 'booking' AND p.order_id = b.id AND p.status = 'paid'
WHERE b.hotel_id != p.hotel_id;

-- 检查已支付但状态未更新的预订
SELECT b.id, b.status, p.status as payment_status
FROM bookings b
JOIN payments p ON p.order_type = 'booking' AND p.order_id = b.id AND p.status = 'paid'
WHERE b.status = 'pending';

-- 检查重复支付记录
SELECT order_id, order_type, COUNT(*) as cnt
FROM payments WHERE status = 'paid'
GROUP BY order_id, order_type
HAVING cnt > 1;
```

## 4. 重启测试规范

### 4.1 后端重启

```powershell
# 1. 杀掉旧进程
netstat -ano | findstr ":3000" | findstr "LISTENING"
taskkill /PID <PID> /F

# 2. 启动后端
cd backend/iot-hotel-backend
npm run dev
```

### 4.2 Web前端重启

```powershell
cd frontend/iot-hotel-web
npm run dev
```

### 4.3 App重启

```powershell
cd mobile/iot_hotel_app
flutter run -d windows
```

### 4.4 重启后验证清单

| 序号 | 验证项     | 方法                        |
| -- | ------- | ------------------------- |
| 1  | 后端启动成功  | 日志显示"服务器启动成功"             |
| 2  | API可访问  | GET /api/v1 返回模块列表        |
| 3  | 登录功能    | 使用测试账号登录                  |
| 4  | 预订查询    | GET /api/v1/bookings 返回数据 |
| 5  | Web页面加载 | 浏览器访问前端页面                 |
| 6  | App编译通过 | flutter analyze 无错误       |
| 7  | App运行正常 | 登录、查看预订功能正常               |
