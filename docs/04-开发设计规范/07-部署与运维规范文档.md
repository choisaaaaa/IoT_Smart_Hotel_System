## 3. 启动与停止

### 3.1 后端启动

```powershell
cd backend/iot-hotel-backend
npm install          # 首次或依赖变更时
npm run dev          # 开发模式（nodemon热重载）
```

### 3.2 后端停止

```powershell
# 查找占用端口的进程
netstat -ano | findstr ":3000" | findstr "LISTENING"
# 终止进程
taskkill /PID <PID> /F
```

### 3.3 Web前端启动

```powershell
cd frontend/iot-hotel-web
npm install
npm run dev
```

### 3.4 App启动

```powershell
cd mobile/iot_hotel_app
flutter pub get      # 首次或依赖变更时
flutter run -d windows
```

## 4. 数据库运维

### 4.1 连接数据库

```powershell
mysql -h 8.134.166.69 -P 3306 -u iot_user -pIot2026. iot_hotel_system
```

### 4.2 常用运维SQL

```sql
-- 查看所有表
SHOW TABLES;

-- 查看表结构
DESCRIBE bookings;

-- 检查数据一致性
SELECT b.id, b.status, b.hotel_id, p.hotel_id as payment_hotel_id
FROM bookings b
LEFT JOIN payments p ON p.order_type = 'booking' AND p.order_id = b.id AND p.status = 'paid'
WHERE b.hotel_id != p.hotel_id AND p.id IS NOT NULL;

-- 重置测试账号密码（bcrypt hash for '123123'）
-- 需要先在Node.js中生成hash:
-- node -e "console.log(require('bcryptjs').hashSync('123123', 10))"
UPDATE users SET password = '<generated_hash>' WHERE phone = '13900000006';
```

## 5. 常见问题排查

### 5.1 端口占用

```powershell
netstat -ano | findstr ":3000"
taskkill /PID <PID> /F
```

### 5.2 后端启动失败

1. 检查端口是否被占用
2. 检查数据库连接是否正常
3. 检查 npm install 是否完成
4. 查看 nodemon 日志中的错误信息

### 5.3 App编译错误

```powershell
flutter clean
flutter pub get
flutter analyze --no-fatal-infos
```

### 5.4 数据不同步排查

1. 检查数据库中 bookings 和 payments 的 hotel_id 是否一致
2. 检查已支付的订单状态是否已更新为 confirmed
3. 检查顾客的 hotel_id 是否为 0
4. 使用本文档中的"数据库一致性验证SQL"进行检查
