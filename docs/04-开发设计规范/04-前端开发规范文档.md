## 3. 开发规范

### 3.1 状态管理规范

**统一使用** **`useAppStore`**，项目未定义 `useUserStore`：

```typescript
// 正确 ✅
import { useAppStore } from '@/stores/app'
const appStore = useAppStore()

// 错误 ❌ - 项目中不存在 useUserStore
const userStore = useUserStore()
```

**appStore 提供的属性**：

- `appStore.role` - 当前用户角色
- `appStore.hotel_id` - 当前酒店ID
- `appStore.user` - 当前用户信息

### 3.2 角色判断规范

使用 `CANONICAL_ROLES` 常量进行角色判断：

```typescript
import { CANONICAL_ROLES } from '@/api/auth'

const isSystemAdmin = computed(() => appStore.role === CANONICAL_ROLES.SYSTEM_ADMIN)
const isAdmin = computed(() => appStore.role === CANONICAL_ROLES.HOTEL_ADMIN)
const isStaff = computed(() => appStore.role === CANONICAL_ROLES.STAFF)
```

### 3.3 API请求规范

统一使用 `request` 实例：

```typescript
import request from '@/api/request'

// GET请求
const data = await request.get('/api/v1/bookings', { params: { page: 1 } })

// POST请求
const result = await request.post('/api/v1/bookings', payload)
```

### 3.4 页面视图规范

| 视图目录               | 角色            | 说明        |
| ------------------ | ------------- | --------- |
| `views/admin/`     | hotel\_admin  | 酒店管理员操作页面 |
| `views/guest/`     | customer      | 顾客端页面     |
| `views/reception/` | staff         | 前台员工操作页面  |
| `views/system/`    | system\_admin | 系统管理员页面   |

### 3.5 状态过滤规范

前台端显示今日预订时，必须包含所有活跃状态：

```typescript
// 正确 ✅ - 包含所有需要显示的状态
const activeBookings = allList.filter((item) =>
  ['pending', 'confirmed', 'pre_checked_in', 'checked_in'].includes(item.status)
)

// 错误 ❌ - 遗漏 confirmed 状态
const activeBookings = allList.filter((item) =>
  ['pending', 'pre_checked_in'].includes(item.status)
)
```

### 3.6 组件命名规范

| 类型   | 命名格式       | 示例                                   |
| ---- | ---------- | ------------------------------------ |
| 页面组件 | PascalCase | `CheckInOut.vue`, `MyOrders.vue`     |
| 布局组件 | XxxLayout  | `AdminLayout.vue`, `GuestLayout.vue` |
| 公共组件 | PascalCase | `DeviceCard.vue`                     |
