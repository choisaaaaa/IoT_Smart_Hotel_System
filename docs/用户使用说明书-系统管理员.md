# 智慧酒店物联网控制系统 - 系统管理员使用说明书

## 📋 系统概述

智慧酒店物联网控制系统是一个基于现代 Web 技术栈的综合管理平台，旨在为酒店提供智能化、自动化的运营管理解决方案。作为系统管理员，您拥有最高权限，可以管理所有酒店、用户和系统配置。

## 🚀 登录系统

1. **访问登录页面**：打开浏览器，输入系统 URL
2. **输入账号信息**：
   - 用户名：系统管理员账号
   - 密码：系统管理员密码
3. **点击登录**：进入系统管理界面

## 🎯 核心功能

### 1. 集团运营总览

- **功能入口**：左侧导航栏 → 集团运营总览
- **功能说明**：
  - 查看集团整体运营数据，包括酒店数、会员数、设备数、总营收等
  - 查看月度营收趋势图
  - 查看酒店营收排名
  - 了解系统整体运行状态

### 2. 酒店管理

- **功能入口**：左侧导航栏 → 酒店维护
- **功能说明**：
  - 查看所有酒店列表
  - **添加酒店**：点击「添加酒店」按钮，填写酒店基本信息
  - **编辑酒店**：点击酒店名称，修改酒店信息
  - **删除酒店**：删除不需要的酒店（谨慎操作）

### 3. 全局设备管理

- **功能入口**：左侧导航栏 → 全局设备管理
- **功能说明**：
  - 查看所有酒店的设备列表
  - 查看设备在线状态
  - 查看设备详情
  - 管理设备信息

### 4. 账户管理

- **功能入口**：左侧导航栏 → 账户管理
- **功能说明**：
  - 查看系统用户列表
  - **添加用户**：点击「添加用户」按钮，填写用户信息和角色
  - **编辑用户**：修改用户信息和权限
  - **删除用户**：删除不需要的用户账号

### 5. 优惠券管理

- **功能入口**：左侧导航栏 → 优惠券管理
- **功能说明**：
  - 查看优惠券列表
  - **添加优惠券**：点击「添加优惠券」按钮，设置优惠券规则
  - **编辑优惠券**：修改优惠券信息
  - **删除优惠券**：删除不需要的优惠券

### 6. 会员方案配置

- **功能入口**：左侧导航栏 → 会员方案配置
- **功能说明**：
  - 配置会员等级名称和权益
  - 设置会员折扣率和积分倍率
  - 配置升级经验值要求
  - 设置积分兑换规则
  - 保存配置并应用到所有酒店

### 7. 分店快速进入

- **功能入口**：左侧导航栏 → 分店快速进入
- **功能说明**：
  - 查看所有酒店列表
  - 点击酒店名称，直接进入该酒店的管理界面
  - 方便快速切换不同酒店进行管理

### 8. MQTT 服务管理

- **功能入口**：左侧导航栏 → MQTT 服务管理
- **功能说明**：
  - 查看 MQTT 服务状态
  - 管理 MQTT 连接配置
  - 查看 MQTT 消息日志
  - 重启 MQTT 服务

## 🔒 权限管理

### 角色权限说明

| 角色 | 权限范围 |
|------|----------|
| **system_admin** | 管理所有酒店及全局配置 |
| **hotel_admin** | 管理本酒店员工、房型、报表 |
| **staff** | 办理入住/退房、处理工单 |
| **customer** | 控制本房间设备、发起服务 |

### 用户权限设置

1. 在「账户管理」页面，点击「添加用户」或「编辑用户」
2. 选择用户角色
3. 对于酒店管理员和前台员工，选择所属酒店
4. 保存设置

## ❓ 常见问题

### 1. 无法登录系统

**Q: 无法登录系统**
A: 检查账号和密码是否正确，确保网络连接正常。如忘记密码，请联系技术支持。

### 2. 无法添加酒店

**Q: 点击「添加酒店」按钮无反应**
A: 检查浏览器是否支持，尝试刷新页面，如问题持续，请联系技术支持。

### 3. 会员方案配置不生效

**Q: 配置会员方案后，会员等级未更新**
A: 保存配置后，系统需要一定时间同步到所有酒店，请耐心等待。如长时间未生效，请联系技术支持。

### 4. MQTT 服务连接失败

**Q: MQTT 服务显示连接失败**
A: 检查 MQTT 服务是否运行，网络连接是否正常，配置是否正确。如问题持续，请联系技术支持。
