# 智慧酒店物联网控制系统 - 酒店管理员使用说明书

## 📋 系统概述

智慧酒店物联网控制系统是一个基于现代 Web 技术栈的综合管理平台，旨在为酒店提供智能化、自动化的运营管理解决方案。作为酒店管理员，您拥有管理本酒店所有资源和运营的权限。

## 🚀 登录系统

1. **访问登录页面**：打开浏览器，输入系统 URL
2. **输入账号信息**：
   - 用户名：酒店管理员账号
   - 密码：酒店管理员密码
3. **点击登录**：进入酒店管理界面

## 🎯 核心功能

### 1. 总览仪表盘

- **功能入口**：左侧导航栏 → 总览仪表盘
- **功能说明**：
  - 查看酒店实时运营数据
  - 查看今日营收、本月累计营收、待结算账单数
  - 查看近7日营收趋势
  - 了解酒店整体运行状态

### 2. 设备监控

- **功能入口**：左侧导航栏 → 设备监控
- **功能说明**：
  - 查看酒店所有设备的在线状态
  - 点击设备名称查看设备详情
  - 发送控制指令控制设备
  - 查看设备历史数据

### 3. 环境监测

- **功能入口**：左侧导航栏 → 环境监测
- **功能说明**：
  - 查看各楼层、房间的温湿度及烟雾报警状态
  - 查看环境数据趋势图
  - 接收环境异常报警

### 4. 房间管理

- **功能入口**：左侧导航栏 → 房间管理
- **功能说明**：
  - 查看房间列表
  - **添加房间**：点击「添加房间」按钮，填写房间信息
  - **编辑房间**：修改房间信息
  - **更新房间状态**：设置房间状态（空闲、在住、打扫中、维保中）

### 5. 房型维护

- **功能入口**：左侧导航栏 → 房型维护
- **功能说明**：
  - 查看房型列表
  - **添加房型**：点击「添加房型」按钮，填写房型信息
  - **编辑房型**：修改房型信息和基础价格
  - **上传房型图片**：上传房型图片

### 6. 楼层管理

- **功能入口**：左侧导航栏 → 楼层管理
- **功能说明**：
  - 查看楼层列表
  - **添加楼层**：点击「添加楼层」按钮，填写楼层信息
  - **编辑楼层**：修改楼层信息
  - **上传楼层平面图**：上传楼层平面图

### 7. 酒店信息编辑

- **功能入口**：左侧导航栏 → 酒店信息编辑
- **功能说明**：
  - 修改酒店基本信息
  - 上传酒店 logo
  - 编辑酒店描述
  - 保存酒店信息

### 8. 价格日历

- **功能入口**：左侧导航栏 → 价格日历
- **功能说明**：
  - 设置不同日期的房型价格
  - 调整房间库存
  - 查看价格趋势
  - 批量更新价格

### 9. 优惠券管理

- **功能入口**：左侧导航栏 → 优惠券管理
- **功能说明**：
  - 查看优惠券列表
  - **添加优惠券**：点击「添加优惠券」按钮，设置优惠券规则
  - **编辑优惠券**：修改优惠券信息
  - **删除优惠券**：删除不需要的优惠券

### 10. 账单报表

- **功能入口**：左侧导航栏 → 账单报表
- **功能说明**：
  - 查看酒店营收报表
  - 查看账单明细
  - 导出报表数据
  - 分析营收趋势

### 11. 用户管理

- **功能入口**：左侧导航栏 → 用户管理
- **功能说明**：
  - 查看本酒店用户列表
  - **添加用户**：点击「添加用户」按钮，填写用户信息
  - **编辑用户**：修改用户信息和权限
  - **删除用户**：删除不需要的用户账号

### 12. AI 知识库

- **功能入口**：左侧导航栏 → AI 知识库
- **功能说明**：
  - 维护酒店知识库
  - **添加知识条目**：点击「添加知识条目」按钮，填写知识内容
  - **编辑知识条目**：修改知识内容
  - **删除知识条目**：删除不需要的知识条目
  - **切换知识条目启用状态**：启用或禁用知识条目

### 13. 评价管理

- **功能入口**：左侧导航栏 → 评价管理
- **功能说明**：
  - 查看酒店评价列表
  - 回复评价
  - 处理评价申诉
  - 查看评价统计

### 14. MQTT 通信管理

- **功能入口**：左侧导航栏 → MQTT 通信管理
- **功能说明**：
  - 查看 MQTT 服务状态
  - 管理 MQTT 连接配置
  - 查看 MQTT 消息日志

## 🔒 权限管理

### 本酒店用户权限设置

1. 在「用户管理」页面，点击「添加用户」或「编辑用户」
2. 选择用户角色（酒店管理员、前台员工）
3. 保存设置

## ❓ 常见问题

### 1. 无法登录系统

**Q: 无法登录系统**
A: 检查账号和密码是否正确，确保网络连接正常。如忘记密码，请联系系统管理员。

### 2. 无法添加房型

**Q: 点击「添加房型」按钮无反应**
A: 检查浏览器是否支持，尝试刷新页面，如问题持续，请联系技术支持。

### 3. 设备控制失败

**Q: 发送控制指令后设备无响应**
A: 检查设备是否在线，网络连接是否正常，MQTT 服务是否运行。如问题持续，请联系技术支持。

### 4. 价格日历设置不生效

**Q: 设置价格后，预订页面显示价格未更新**
A: 保存设置后，系统需要一定时间同步，，请耐心等待。如长时间未生效，请联系技术支持。
