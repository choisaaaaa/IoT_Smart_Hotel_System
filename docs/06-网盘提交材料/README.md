## 使用说明

### 1. 占位文件说明
每个文件夹中的文件为**占位文件**，包含：
- 配图编号
- 配图名称
- 内容要求
- 交付标准
- 制作建议

### 2. 替换方式
请各负责人：
1. 打开自己对应的文件夹
2. 查看每个占位文件的要求
3. 制作/拍摄实际配图
4. **删除占位文件**，替换为实际图片
5. 保持文件名与占位文件一致

### 3. 文件命名规范
```
格式：[章节号]_[配图名称].[扩展名]
示例：
  - 03_全栈架构概览图.png
  - 04_管理端_Dashboard.png
  - 05_前台管理端实物.jpg
```

### 4. 格式要求
| 类型 | 格式 | 分辨率 | 大小 |
|------|------|--------|------|
| 界面截图 | PNG | 1920×1080 | < 2MB |
| 架构图/流程图 | PNG | 300dpi | < 5MB |
| 实物照片 | JPG | 1920×1080 | < 3MB |
| 手机截图 | PNG | 实际分辨率 | < 1MB |
