## 引用格式规范

在正文中引用图片时，使用以下格式：
```markdown
如图 X-Y 所示，...（图片描述）...

![图 X-Y：图片标题](图片路径)
```

其中：
- `X` = 章节号（1-10，附录为A）
- `Y` = 图片在章节内的序号
