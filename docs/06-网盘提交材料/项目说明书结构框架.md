## 六、云边端协同机制

### 6.1 数据流转架构

```
传感器采集 → 边缘预处理 → MQTT上报 → 云端存储 → 业务处理 → 前端展示
                ↑                                      ↓
              本地决策                              指令下发
                ↑                                      ↓
              离线自治 ←──────────────────────── 云端策略
```

### 6.2 关键协同场景

| 场景         | 云端            | 边缘          | 设备端         |
| ---------- | ------------- | ----------- | ----------- |
| **环境自适应**  | 分析历史数据，生成调控策略 | 接收策略，本地决策执行 | 传感器采集，执行器响应 |
| **入住联动**   | 预订状态变更        | 权限下发到客房终端   | 门锁激活，欢迎模式启动 |
| **安防预警**   | 接收告警，推送通知     | 本地判断，紧急处理   | 传感器触发，本地报警  |
| **AI语音控制** | NLP解析，意图识别    | 指令转发        | 语音采集，设备执行   |

### 6.3 离线自治能力

- [ ] 网络断开时，边缘层继续本地控制
- [ ] 设备状态本地缓存，恢复后同步
- [ ] 紧急场景（火灾/SOS）本地优先响应
