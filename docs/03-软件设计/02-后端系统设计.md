# 智慧酒店物联网控制系统 - 后端系统设计

## 📋 功能定位

后端 API 服务（`iot-hotel-backend`）是整个系统的核心枢纽，负责连接硬件终端、前端应用和 AI 引擎。它不仅承担了传统酒店业务逻辑的处理，还作为物联网数据的中转站和处理中心。

---

## 🏗️ 核心子系统设计

### 1. 设备控制与通信子系统
- **MQTT 集成**：采用 `MQTT.js` 客户端，实现对 ESP32 设备的实时控制和状态监听。
- **Topic 设计**：
  - `hotel/{hotel_id}/room/{room_id}/device/{device_id}/{action}`: 下发控制指令（如灯光、空调）。
  - `hotel/{hotel_id}/room/{room_id}/device/{device_id}/status`: 接收设备上报的状态数据。
  - `hotel/{hotel_id}/floor/{floor_id}/environment`: 接收楼控环境传感器数据。
- **状态同步**：当设备状态变更时，后端自动通过 WebSocket 推送至所有连接的前端管理端。
- **房卡管理**：支持房卡生成、发卡操作、权限管理。
- **传感器数据**：环境数据采集、数据存储、数据分析。

### 2. AI 智能管家子系统
- **NLP 引擎**：集成智谱 AI GLM-4 模型，实现多轮对话和意图识别。
- **Function Calling**：定义了设备控制、工单查询、酒店信息检索等工具函数，AI 可根据用户指令自动调用。
- **语音协同**：与前端 ASR/TTS 配合，实现完整的语音交互闭环。
- **知识库管理**：支持酒店管理员维护知识库，AI 管家回复时只能使用已启用的知识库数据。

### 3. 接待与预订管理子系统
- **动态定价**：支持价格日历功能，可根据日期设置不同的房型价格。
- **房态管理**：实时管理房间状态（空闲、在住、打扫中、维保中）。
- **流程自动化**：入住自动激活房卡权限，退房自动断开客房电源（通过物联网指令）。
- **入住用户关联**：前台办理入住时，系统自动通过手机号匹配用户账号（user_id），确保顾客端能正确识别入住状态和入住房间。
- **现场打折与经理授权**：前台端支持现场手动打折（折扣率或直减金额），该操作必须通过当前门店经理的二次密码授权。授权成功后，后端根据手动优惠重新计算并更新订单最终价格。
- **自动退房服务**：系统每分钟轮询检查已超时未退房的订单（auto_checkout_at < NOW()），自动执行退房流程，释放房间资源。
- **在线续住**：顾客可在入住期间发起续住申请，系统自动计算续住价格（含会员折扣、优惠券抵扣、积分抵扣），检查日期冲突后更新退房日期和总价，创建支付记录。
- **在线入住**：顾客可在线提交身份信息，办理预入住，系统将状态改为 `pre_checked_in`，支持传入 `room_id` 进行物理房间绑定。

### 4. 实时通信 (WebSocket) 子系统
- **Socket.io 应用**：
  - **语音通话**：基于 WebSocket 实现前台与客房/手机端的双向双工语音呼叫。
  - **实时报警**：SOS 报警信息毫秒级推送至前台界面。
  - **数据大屏**：全局实时数据更新，无需手动刷新。
  - **设备状态变更**：设备在线/离线或状态变更提醒。
  - **新订单通知**：收到新的预订或服务订单。

### 5. 客房服务子系统
- **送物服务**：送物订单管理、状态更新、通知提醒。
- **报修服务**：报修工单管理、优先级设置、处理跟踪。
- **语音通话**：房间与前台通话、通话记录管理。

### 6. 会员与营销子系统
- **会员管理**：会员信息管理、会员等级、积分管理。
- **优惠券管理**：优惠券定义、发放、使用。
- **会员方案**：会员等级配置、权益设置、积分规则。

### 7. 评价与反馈子系统
- **评价管理**：服务评价收集、评价统计、评价回复。
- **申诉处理**：评价申诉管理、申诉审核、申诉处理。

### 8. 系统配置子系统
- **全局设置**：系统参数配置、会员方案配置。
- **酒店个性化设置**：酒店特定配置、品牌设置。

### 9. 环境监测子系统
- **数据采集**：通过 MQTT 接收环境传感器数据。
- **数据分析**：对环境数据进行分析和处理。
- **数据可视化**：提供环境数据的可视化接口。

## 🔒 安全性设计

- **身份认证**：基于 JWT (JSON Web Token) 的无状态认证，支持过期自动刷新。
- **权限隔离**：
  - `system_admin`: 集团超管，管理所有酒店及全局配置。
  - `hotel_admin`: 门店经理，管理本酒店员工、房型、报表（仅可访问本酒店数据）。
  - `staff`: 前台员工，办理入住/退房、处理工单。
  - `customer`: 普通住客，控制本房间设备、发起服务（仅可访问自己入住房间的设备）。
- **设备安全**：设备连接需携带预设的 `device_key`，防止非法设备接入。
- **数据加密**：敏感数据（如用户密码）采用 `bcrypt` 强哈希存储。
- **请求频率限制**：使用 Express-rate-limit 防止暴力破解和 DoS 攻击。
- **CORS 配置**：合理配置 CORS 策略，确保跨域安全。
- **Helmet 安全头部**：使用 Helmet 库设置安全相关的 HTTP 头部。

## 📡 API 接口设计

### 1. 认证与账户 (`/auth`)
- `POST /auth/login`: 用户登录 (手机号/密码)，返回 JWT Token。
- `GET /auth/me`: 获取当前登录用户信息及权限。
- `POST /auth/register`: 新用户注册。
- `POST /auth/logout`: 登出系统，注销会话。
- `POST /users/authorize-manager`: 经理授权校验 (用于现场打折等特权操作)。
- `POST /auth/qr-generate`: 生成扫码登录二维码Token（无需认证，5分钟有效）。
- `POST /auth/qr-confirm`: APP确认扫码登录（需JWT认证，关联Token与APP用户）。
- `GET /auth/qr-status`: Web端轮询扫码状态（无需认证，返回pending/confirmed/expired）。

### 2. 酒店资源管理 (`/hotels`, `/rooms`, `/room-types`, `/price-calendar`)
- `GET /hotels/search`: 根据目的地和日期搜索酒店。
- `GET /hotels/:id/rooms/availability`: 查询指定酒店的房型余量及价格。
- `GET /rooms`: 获取房间列表 (支持分页及状态、房型 ID、楼层等筛选)。
- `PATCH /rooms/:id/status`: 更新房间状态 (空闲/在住/清洁等)。
- `GET /room-types`: 获取所有房型定义及基础价格（按酒店过滤）。
- `GET /floors`: 获取楼层列表及平面图。
- `GET /price-calendar/today`: 获取今日各房型、各方案的可售余量与挂牌价格。
- `POST /price-calendar/today/update`: 实时更新今日房型余量与价格。

### 3. 物联网设备控制 (`/devices`)
- `GET /devices`: 获取设备列表及在线状态。
- `GET /devices/:id`: 获取设备详情。
- `POST /devices/:id/command`: 发送控制指令，指令通过 MQTT 转发至硬件。
- `POST /devices/room-card`: 发卡/房卡操作。
- `GET /devices/:id/history`: 查询设备的传感器历史数据。

### 4. 业务订单系统 (`/bookings`, `/payments`)
- `POST /bookings`: 创建客房预订。
- `GET /bookings/lookup`: 顾客查询预订（用于在线入住前验证）。
- `GET /bookings/calculate-price`: 预计算订单总价 (考虑优惠券、会员折扣及手动打折)。
- `PUT /bookings/:id/checkin`: 办理入住，激活房卡。
- `POST /bookings/:id/checkin-online`: 顾客在线办理入住。
- `PUT /bookings/:id/checkout`: 办理退房，结清账单。
- `PUT /bookings/:id/cancel`: 取消预订。
- `POST /bookings/:id/extend-price`: 计算续住价格。
- `PUT /bookings/:id/extend`: 提交续住申请。
- `POST /payments/create`: 发起支付请求。

### 5. 客房服务与通信 (`/delivery`, `/maintenance`, `/calls`)
- `POST /delivery`: 下单送物服务。
- `POST /maintenance`: 提交报修工单。
- `GET /calls/active`: 获取当前正在进行的语音通话。
- `POST /calls/initiate`: 发起呼叫请求。

### 6. AI 智能管家 (`/ai-butler`)
- `POST /ai-butler/chat`: 发送文本/语音指令，获取 AI 响应及 Function Calling 结果。
- `GET /ai-butler/config`: 获取 AI 管家的个性化配置。

### 7. AI 知识库管理 (`/knowledge-base`)
- `GET /knowledge-base`: 获取知识库列表。
- `GET /knowledge-base/:id`: 获取单个知识条目。
- `PUT /knowledge-base/:category`: 创建或更新知识条目。
- `PATCH /knowledge-base/:id/toggle`: 切换知识条目启用状态。
- `DELETE /knowledge-base/:id`: 删除知识条目。
- `POST /knowledge-base/init`: 批量初始化知识库。

### 8. 系统全局配置 (`/system-config`)
- `GET /system-config`: 获取所有系统配置。
- `GET /system-config/:key`: 获取单个配置项。
- `POST /system-config`: 批量更新配置。

### 9. 评价与申诉系统 (`/reviews`)
- `GET /reviews`: 获取评价列表。
- `GET /reviews/:id`: 获取评价详情。
- `GET /reviews/my`: 获取我的评价。
- `GET /reviews/stats`: 获取评价统计。
- `POST /reviews`: 创建评价。
- `PUT /reviews/:id`: 修改评价。
- `DELETE /reviews/:id`: 删除评价。
- `POST /reviews/:id/reply`: 回复评价。
- `GET /reviews/appeals`: 获取申诉列表。
- `POST /reviews/appeals`: 创建申诉。
- `PUT /reviews/appeals/:id`: 处理申诉。
