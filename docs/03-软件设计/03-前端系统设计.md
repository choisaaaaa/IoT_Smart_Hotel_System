# 智慧酒店物联网控制系统 - 前端系统设计

## 📋 功能定位

前端系统（`iot-hotel-web`）采用 Vue 3 全家桶开发，实现了一套多角色、多端自适应的智慧化交互界面。系统支持前台管理端、住客移动端、集团管理端等多个角色的操作界面，提供了丰富的功能和良好的用户体验。

---

## 🏗️ 核心功能模块

### 1. 🏨 接待与运营中心 (Reception Center)
> **服务角色**：前台员工 (`staff`)、酒店管理员 (`hotel_admin`)
- **接待中心**：可视化房态图，一键办理入住/退房，自动关联房卡物理读写。
- **现场打折授权**：支持在办理入住时，通过经理账号输入密码进行实时打折授权（折扣率/立减），系统自动重新计算应付金额。
- **实时监控**：集成环境监测仪表盘，实时查看各楼层、房间的温湿度及烟雾报警状态。
- **工单管理**：响应住客发起的送物、报修请求，派单至对应员工。
- **语音通话**：网页端直连客房/住客手机，支持双向语音对讲。
- **预订管理**：管理客房预订，查看预订状态，处理预订请求。
- **客房余量**：实时查看客房余量，了解房间状态分布。
- **账单报表**：查看酒店营收报表，了解经营状况。
- **价格管理**：管理价格日历，调整房型价格。

### 2. 📱 住客智能服务 (Guest Service)
> **服务角色**：住客 (`customer`)
- **智能客房控制**：图形化控制灯光、空调、窗帘，支持情景模式（睡眠、娱乐、阅读）。
- **AI 语音管家**：悬浮式 AI 助手，支持文字或语音输入，实现设备控制及酒店信息咨询。
- **自助服务**：在线查看消费账单、申请开票、一键发起服务请求。
- **在线续住**：入住期间可在线发起续住申请，选择续住天数，自动计算含会员折扣、优惠券抵扣、积分抵扣的续住价格，支持余额/微信/支付宝支付。
- **会员资产**：可视化会员等级、积金、优惠券及个人消费足迹。
- **在线入住**：在线提交身份信息，办理预入住。
- **我的订单**：查看历史订单，了解订单状态。
- **个人中心**：管理个人信息，查看会员权益。

### 3. 📊 集团/门店管理 (Admin/System)
> **服务角色**：酒店管理员 (`hotel_admin`)、系统管理员 (`system_admin`)
- **全局仪表盘**：多维数据分析，包括出租率、营收趋势、设备在线率等。
- **资源管理**：酒店信息编辑、房型定义、价格日历配置、员工账户管理。
- **系统设置**：全局参数配置、系统日志审计、设备固件管理。
- **设备监控**：实时监控设备状态，查看设备在线情况。
- **环境监测**：查看环境数据，分析环境趋势。
- **楼层管理**：管理楼层信息，上传楼层平面图。
- **AI 知识库**：维护 AI 管家知识库，管理知识条目。
- **评价管理**：管理服务评价，处理评价申诉。
- **优惠券管理**：管理优惠券，设置优惠券规则。
- **会员方案配置**：配置会员等级、权益及积分规则。

## 🎨 交互与 UI 设计

### 技术亮点
- **响应式布局**：基于 Ant Design Vue 的 Grid 系统，完美适配 iPad、手机及前台宽屏电脑。
- **动态皮肤**：根据入住酒店的品牌色动态调整 UI 主题。
- **图表可视化**：使用 ECharts 实现复杂的环境趋势图及营收统计图。
- **动画反馈**：采用 Lottie 动画及 CSS 3 实现流畅的设备开关状态过渡。
- **实时通信**：基于 WebSocket 的实时数据推送，确保数据及时更新。
- **语音交互**：集成 WebRTC 实现语音通话功能。

### 🧩 核心组件设计
- **`Layout` 架构**：
  - `AdminLayout`: 侧边栏导航模式，适用于桌面端管理。
  - `GuestLayout`: 底部 Tab 导航模式，适用于手机端体验。
  - `ReceptionLayout`: 前台专用布局，强调接待功能。
  - `SystemLayout`: 系统管理员专用布局，强调全局管理。
- **`DeviceControl` 组件**：封装了 MQTT 指令下发逻辑，支持滑块（亮度/温度）和开关。
- **`WSCall` 组件**：基于 WebRTC/WebSocket 的实时语音组件。
- **`KnowledgeBaseWizard` 组件**：AI 知识库管理向导，支持知识条目编辑和管理。
- **`IncomingCallModal` 组件**：来电弹窗组件，支持接听和拒绝通话。

## 🔒 权限管理

前端路由权限控制基于 Vue Router 的导航守卫，实现了以下权限控制逻辑：

1. **登录状态检查**：对于需要认证的路由，检查是否存在 JWT Token。
2. **角色权限检查**：根据用户角色，限制访问对应权限的路由。
3. **动态路由生成**：根据用户角色动态生成可访问的路由列表。
4. **权限拦截**：当用户尝试访问无权限的路由时，重定向到对应角色的默认页面。

## 📡 通信协议

### 1. HTTP/HTTPS 通信
- **API 调用**：使用 Axios 库进行 HTTP 请求，封装了请求拦截器和响应拦截器。
- **认证**：在请求头中携带 JWT Token 进行身份验证。
- **数据格式**：使用 JSON 格式进行数据交换。

### 2. WebSocket 通信
- **实时数据**：使用 Socket.io-client 库建立 WebSocket 连接，实现实时数据推送。
- **事件监听**：监听设备状态变更、新订单通知、报警信息等事件。
- **语音通话**：基于 WebSocket 实现语音通话信令交换。

### 3. MQTT 通信
- **设备控制**：通过后端 API 间接调用 MQTT 服务，实现设备控制。

## 🚀 性能优化

### 1. 代码分割
- **路由懒加载**：使用动态导入实现路由懒加载，减少初始加载时间。
- **组件懒加载**：对于大型组件，使用动态导入实现懒加载。

### 2. 缓存策略
- **浏览器缓存**：合理设置静态资源的缓存策略。
- **内存缓存**：使用 Pinia 状态管理存储常用数据，减少重复请求。

### 3. 网络优化
- **请求合并**：合并多个相关请求，减少网络开销。
- **请求防抖**：对频繁触发的请求进行防抖处理，避免重复请求。

### 4. 渲染优化
- **虚拟列表**：对于长列表，使用虚拟列表减少 DOM 节点数量。
- **按需渲染**：只渲染可视区域内的内容，减少渲染负担。
