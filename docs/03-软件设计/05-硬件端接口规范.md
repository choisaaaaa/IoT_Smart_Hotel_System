# 智慧酒店物联网系统 - 硬件端接口规范 (v3.6.0)

本规范定义了硬件设备（门锁、控制器、传感器）与后端系统之间的通信协议，主要基于 MQTT 协议实现异步交互，部分敏感操作支持 HTTP API。

## 1. 通信基础
- **协议**: MQTT v3.1.1
- **消息格式**: JSON
- **安全校验**: 基于 `device_key` 的 HMAC-SHA256 签名校验
- **Topic 根路径**: `hotel/devices/{device_id}/`

---

## 2. 门锁业务接口 (Door Lock)

### 2.1 门锁状态上报 (Status Report)
**Topic**: `hotel/devices/{device_id}/status/report`
**方向**: 硬件 -> 后端
**Payload**:
```json
{
  "timestamp": 1713850000,
  "lock_state": "closed",      // closed, open, unlocked_timeout, forced_open
  "internal_deadbolt": 0,      // 0-未反锁, 1-已反锁
  "battery_level": 85,         // 0-100
  "last_event": {
    "type": "rfid",            // rfid, app, physical_key, remote
    "uid": "A1B2C3D4",         // 仅RFID开门时带上
    "result": "success"
  },
  "signature": "hmac_sha256_result"
}
```

### 2.2 刷卡鉴权请求 (Card Auth - 离线卡除外)
**Topic**: `hotel/devices/{device_id}/auth/request`
**方向**: 硬件 -> 后端
**Payload**:
```json
{
  "card_uid": "A1B2C3D4",
  "reader_id": "door_external",
  "timestamp": 1713850000
}
```
**响应 Topic**: `hotel/devices/{device_id}/auth/response`
**响应 Payload**:
```json
{
  "allow": true,
  "unlock_duration": 5000,     // 毫秒
  "identity_type": "guest",    // guest, staff, visitor
  "welcome_msg": "Welcome, Mr. Zhang"
}
```

## 3. 房间占用检测接口 (Occupancy)

### 3.1 复合数据上报 (Composite Report)
**Topic**: `hotel/devices/{device_id}/occupancy/report`
**方向**: 硬件 -> 后端
**Payload**:
```json
{
  "pir_activity": true,        // 是否有人体红外活动
  "card_power_state": 1,       // 插卡取电状态：0-无卡, 1-有卡
  "power_consumption": 150.5,  // 当前即时功率 (W)
  "timestamp": 1713850000
}
```

---

## 4. 房卡管理接口 (Card Lifecycle)

### 4.1 物理卡重置指令 (Card Reset)
**Topic**: `hotel/devices/{device_id}/card/reset`
**方向**: 后端 -> 硬件
**Payload**:
```json
{
  "card_uid": "A1B2C3D4",
  "action": "reset",           // 擦除卡内扇区数据
  "operator_id": 101
}
```

## 5. 安全规范 (Security)

### 5.1 签名计算规则
1. 将 JSON 中除 `signature` 外的所有字段按 Key 字典序排序。
2. 拼接成查询字符串格式：`key1=val1&key2=val2...`。
3. 使用 `device_key` 作为密钥，执行 HMAC-SHA256。
4. 结果转为 Hex 字符串。

### 5.2 离线策略
- **门锁**: 硬件应存储最近 100 张有效房卡的白名单。
- **断网**: 发生断网时，硬件应进入离线模式，仅允许白名单卡片通行，并本地存储开门日志，联网后补发。

---

## 6. 错误码定义
| 错误码 | 说明 | 硬件动作 |
|:---:|:---|:---|
| 4001 | 签名验证失败 | 记录日志，忽略指令 |
| 4002 | 设备未授权/未激活 | 红灯闪烁，禁止开门 |
| 4003 | 房卡已过期/无权进入 | 蜂鸣器长鸣，禁止开门 |
| 5001 | 后端数据库异常 | 尝试离线模式开门 |
