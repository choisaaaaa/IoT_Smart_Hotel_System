# 智慧酒店物联网控制系统 - 数据库设计文档

## 📋 数据库概述

系统采用 MySQL 8.0 作为核心关系型数据库，存储用户信息、酒店资源、业务订单及物联网设备元数据。

---

## 🏗️ 核心数据表设计

### 1. 组织架构与账户
| 表名 | 说明 | 关键字段 |
|:---:|:---:|:---|
| `hotels` | 酒店门店表 | `hotel_name`, `hotel_star`, `logo`, `description` |
| `users` | 系统用户表 | `username`, `phone`, `role`, `hotel_id`, `avatar` |
| `roles` | 角色定义表 | `role_name`, `permissions` |
| `user_hotels` | 员工关联表 | `user_id`, `hotel_id` (支持一人管理多店) |

### 2. 客房与资源管理
| 表名 | 说明 | 关键字段 |
|:---:|:---:|:---|
| `room_types` | 房型定义表 | `name`, `code`, `base_price`, `images` (JSON) |
| `rooms` | 房间表 | `room_number`, `room_type`, `room_name`, `room_status`, `hotel_id` |
| `room_prices` | 价格日历表 | `room_type_id`, `price_date`, `final_price` |
| `floors` | 楼层信息表 | `floor_number`, `floor_plan_image` |

### 3. 业务订单系统
| 表名 | 说明 | 关键字段 |
|:---:|:---:|:---|
| `bookings` | 预订订单表 | `booking_number`, `guest_phone`, `check_in_date`, `status`, `user_id`, `auto_checkout_at` |
| `guests` | 住客实名表 | `booking_id`, `guest_name`, `guest_id_number`, `check_in_time` |
| `payments` | 支付流水表 | `payment_no`, `order_id`, `order_type`, `amount`, `payment_method`, `status` |

### 4. 物联网设备与数据
| 表名 | 说明 | 关键字段 |
|:---:|:---:|:---|
| `devices` | 物联网设备表 | `device_id`, `device_type`, `device_key`, `room_id`, `status` |
| `sensor_data` | 传感器历史数据 | `device_id`, `sensor_type`, `value`, `timestamp` |
| `control_commands`| 指令审计表 | `device_id`, `command_type`, `user_id`, `result` |

### 5. 客房服务系统
| 表名 | 说明 | 关键字段 |
|:---:|:---:|:---|
| `delivery_orders` | 送物订单表 | `room_id`, `item_name`, `quantity`, `status` |
| `maintenance_tickets` | 报修工单表 | `room_id`, `fault_type`, `description`, `priority` |
| `calls` | 通话记录表 | `caller_id`, `target_id`, `duration`, `call_type` |

### 6. 会员与营销系统
| 表名 | 说明 | 关键字段 |
|:---:|:---:|:---|
| `members` | 会员资产表 | `phone`, `member_level`, `experience`, `points`, `balance` |
| `coupons` | 优惠券定义表 | `coupon_name`, `discount_value`, `min_spend` |
| `member_coupons` | 用户领券表 | `member_id`, `coupon_id`, `status` |

---

## ⚙️ 数据库配置说明

- **字符集**：`utf8mb4` (支持表情符号及多国语言)
- **存储引擎**：`InnoDB` (支持事务、行级锁)
- **时区配置**：统一采用 `UTC` 时间存储，前端根据本地时区转换。
- **自动更新**：所有业务表均包含 `created_at` 和 `updated_at` 自动时间戳字段。
