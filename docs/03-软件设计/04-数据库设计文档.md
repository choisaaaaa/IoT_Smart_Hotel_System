# 智慧酒店物联网控制系统 - 数据库设计文档

## 📋 数据库概述

系统采用 MySQL 8.0 作为核心关系型数据库，存储用户信息、酒店资源、业务订单及物联网设备元数据。

---

## 🏗️ 核心数据表设计

### 8. 评价与申诉系统
| 表名 | 说明 | 关键字段 |
|:---:|:---:|:---|
| `reviews` | 服务评价表 | `order_id`, `hotel_id`, `room_type_id`, `user_id`, `score`, `environment_rating`, `facility_rating`, `comfort_rating`, `content`, `reply`, `is_deleted` |
| `review_appeals` | 评价申诉表 | `review_id`, `hotel_id`, `appellant_id`, `appeal_reason`, `status`, `handler_id`, `handle_reason` |

**`reviews` 表详细设计：**

| 字段名 | 类型 | 约束 | 说明 |
|:---:|:---:|:---:|:---|
| `id` | INT | PK, AUTO_INCREMENT | 主键ID |
| `order_id` | INT | NOT NULL | 关联订单ID |
| `order_type` | VARCHAR(20) | DEFAULT 'booking' | 订单类型 |
| `member_id` | INT | FK → members(id) | 关联会员ID |
| `hotel_id` | INT | DEFAULT NULL | 酒店ID |
| `room_type_id` | INT | DEFAULT NULL | 房型ID |
| `user_id` | INT | DEFAULT NULL | 评价用户ID（关联users表） |
| `score` | DECIMAL(2,1) | DEFAULT 5.0 | 总体评分（1-5） |
| `environment_rating` | INT | DEFAULT 5 | 环境评分（1-5） |
| `facility_rating` | INT | DEFAULT 5 | 设施评分（1-5） |
| `comfort_rating` | INT | DEFAULT 5 | 舒适评分（1-5） |
| `content` | TEXT | DEFAULT NULL | 评价内容 |
| `photos` | JSON | DEFAULT NULL | 评价图片（JSON数组） |
| `reply` | TEXT | DEFAULT NULL | 酒店回复内容 |
| `replied_at` | DATETIME | DEFAULT NULL | 回复时间 |
| `is_deleted` | TINYINT(1) | DEFAULT 0 | 软删除标记：0=正常，1=已删除 |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**`review_appeals` 表详细设计：**

| 字段名 | 类型 | 约束 | 说明 |
|:---:|:---:|:---:|:---|
| `id` | INT | PK, AUTO_INCREMENT | 主键ID |
| `review_id` | INT | NOT NULL, FK → reviews(id) | 关联评价ID |
| `hotel_id` | INT | NOT NULL | 酒店ID |
| `appellant_id` | INT | NOT NULL | 申诉人ID（酒店管理员） |
| `appeal_reason` | TEXT | NOT NULL | 申诉理由 |
| `status` | ENUM('pending','approved','rejected') | DEFAULT 'pending' | 申诉状态 |
| `handler_id` | INT | DEFAULT NULL | 处理人ID（系统管理员） |
| `handle_reason` | TEXT | DEFAULT NULL | 处理理由 |
| `handled_at` | DATETIME | DEFAULT NULL | 处理时间 |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**评价系统业务约束：**
- 每个订单只能评价一次（防重复评价）
- 只有已退房（checked_out）的订单才能评价
- 顾客只能评价自己的订单
- 评价采用软删除机制（is_deleted标记），删除后不计入统计
- 酒店评分（hotels.rating/review_count）在评价增删时自动更新
- 申诉通过后评价自动软删除
- 同一评价只能有一条待处理的申诉

**`ai_knowledge_base` 表详细设计：**

| 字段名 | 类型 | 约束 | 说明 |
|:---:|:---:|:---:|:---|
| `id` | INT | PK, AUTO_INCREMENT | 主键ID |
| `hotel_id` | INT | NOT NULL, FK → hotels(id) | 关联的酒店ID（各门店独立维护） |
| `category` | VARCHAR(50) | NOT NULL, UNIQUE(hotel_id, category) | 知识分类枚举值 |
| `title` | VARCHAR(200) | NOT NULL | 知识标题 |
| `content` | TEXT | NOT NULL | 知识详细内容（支持Markdown格式） |
| `keywords` | VARCHAR(500) | DEFAULT NULL | 关键词（逗号分隔，用于AI检索匹配） |
| `is_active` | TINYINT(1) | DEFAULT 1 | 是否启用：1=启用，0=禁用 |
| `sort_order` | INT | DEFAULT 0 | 排序权重，数字越大越优先显示 |
| `created_by` | INT | DEFAULT NULL | 创建人用户ID |
| `updated_by` | INT | DEFAULT NULL | 最后更新人用户ID |
| `created_at` | DATETIME | DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| `updated_at` | DATETIME | ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**category 分类枚举值说明：**

| 枚举值 | 中文名称 | 示例内容 |
|:---:|:---:|:---|
| `restaurant` | 餐厅信息 | 营业时间、特色菜品、送餐服务等 |
| `gym` | 健身中心 | 开放时间、设施配置、使用规则等 |
| `wifi` | 网络服务 | WiFi名称、密码、带宽等 |
| `nearby` | 周边推荐 | 交通出行、购物娱乐、医疗资源等 |
| `checkout` | 退房须知 | 退房时间、延迟退房政策等 |
| `breakfast` | 早餐服务 | 用餐时间、餐食类型、特殊需求等 |
| `room_service` | 客房服务 | 保洁、洗衣、物品借用等 |
| `policy` | 酒店政策 | 入住规定、安全须知、停车信息等 |
| `other` | 其他 | 其他自定义知识条目 |

**业务约束：**
- 每个酒店在每个分类下只能有一条记录（UNIQUE KEY）
- 删除酒店时级联删除该酒店的所有知识库数据
- 仅酒店管理员及以上角色可编辑本门店的知识库
- AI管家回复时只能使用已启用（is_active=1）的知识库内容

## ⚙️ 数据库配置说明

- **字符集**：`utf8mb4` (支持表情符号及多国语言)
- **存储引擎**：`InnoDB` (支持事务、行级锁)
- **时区配置**：统一采用 `UTC` 时间存储，前端根据本地时区转换。
- **自动更新**：所有业务表均包含 `created_at` 和 `updated_at` 自动时间戳字段。
