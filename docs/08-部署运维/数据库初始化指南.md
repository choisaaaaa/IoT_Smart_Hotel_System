# 数据库初始化指南

## 问题诊断

**错误日志：**
```
Table 'hotel_system.hotels' doesn't exist
```

**原因：** 
- 初始化脚本创建的数据库名：`iot_hotel_system`
- 后端配置的数据库名：`hotel_system`
- 数据库名不匹配导致表找不到

## 解决方案

### 方案一：修改后端配置（推荐）

修改 `.env` 文件，将数据库名改为 `iot_hotel_system`：

```bash
# 编辑配置文件
sudo vim /root/IoT_Smart_Hotel_System/backend/iot-hotel-backend/.env

# 修改数据库名
DB_NAME=iot_hotel_system

# 重启后端服务
pm2 restart iot-hotel-backend
```

### 方案二：修改初始化脚本

修改 `init.sql`，将数据库名改为 `hotel_system`：

```sql
-- 修改第一行
CREATE DATABASE IF NOT EXISTS hotel_system DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE hotel_system;
```

### 方案三：创建符号链接（临时方案）

```bash
# 创建数据库别名
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS hotel_system;"

# 从 iot_hotel_system 导出数据
mysqldump -u iot_user -p'Iot2026.' -h localhost iot_hotel_system | mysql -u iot_user -p'Iot2026.' -h localhost hotel_system
```

## 推荐操作流程

### 步骤 1：修改后端配置

```bash
# 进入后端目录
cd /root/IoT_Smart_Hotel_System/backend/iot-hotel-backend

# 备份原配置
cp .env .env.backup

# 修改数据库名
sed -i 's/DB_NAME=hotel_system/DB_NAME=iot_hotel_system/' .env

# 验证修改
cat .env | grep DB_NAME
```

### 步骤 2：重启后端服务

```bash
# 重启 PM2
pm2 restart iot-hotel-backend

# 查看日志
pm2 logs iot-hotel-backend --lines 50
```

### 步骤 3：测试 API

```bash
# 测试酒店 API
curl http://localhost/api/v1/hotels

# 测试房间 API
curl http://localhost/api/v1/rooms
```

## 常见问题

### Q: 修改后还是报错

```bash
# 检查 PM2 进程
pm2 status iot-hotel-backend

# 查看详细日志
pm2 logs iot-hotel-backend --lines 100

# 检查数据库连接
mysql -u iot_user -p'Iot2026.' -h localhost iot_hotel_system -e "SHOW TABLES;"
```

### Q: 数据库不存在

```bash
# 创建数据库
mysql -u root -p -e "CREATE DATABASE IF NOT EXISTS iot_hotel_system;"

# 授予权限
mysql -u root -p -e "GRANT ALL PRIVILEGES ON iot_hotel_system.* TO 'iot_user'@'localhost'; FLUSH PRIVILEGES;"
```

### Q: 权限不足

```bash
# 授予用户权限
mysql -u root -p -e "GRANT ALL PRIVILEGES ON iot_hotel_system.* TO 'iot_user'@'localhost'; FLUSH PRIVILEGES;"
```

## 数据库结构说明

**数据库名：** `iot_hotel_system`

**主要表：**
- `hotels` - 酒店信息
- `rooms` - 房间信息
- `bookings` - 预订信息
- `payments` - 支付信息
- `members` - 会员信息
- `coupons` - 优惠券
- `users` - 用户信息
- `employees` - 员工信息
- `devices` - 设备信息
- `sensor_data` - 传感器数据
- `control_commands` - 控制命令
- `delivery_orders` - 送物订单
- `maintenance_tickets` - 维修工单
- `reviews` - 评价
- `calls` - 通话记录
