# 后端 API 500 错误排查指南

## 问题诊断

**症状：** 前端能访问，但 API 请求返回 500 错误
```
/api/v1/hotels: Failed to load resource: the server responded with a status of 500
/api/v1/rooms: Failed to load resource: the server responded with a status of 500
```

## 可能原因

### 1. 后端服务未启动

```bash
# 检查 PM2 进程
pm2 list

# 检查后端服务状态
pm2 status iot-hotel-backend

# 查看后端日志
pm2 logs iot-hotel-backend --lines 100

# 重启后端服务
pm2 restart iot-hotel-backend
```

### 2. 端口配置不匹配

**后端配置 (.env):**
```
APP_PORT=9000
```

**检查后端是否监听 9000 端口：**

```bash
# 检查端口监听
netstat -tuln | grep :9000

# 或使用 lsof
lsof -i :9000
```

### 3. Nginx 代理配置错误

**检查 Nginx 配置：**

```bash
# 查看当前配置
cat /etc/nginx/sites-available/iot-hotel | grep proxy_pass

# 正确配置应该是：
# location /api {
#     proxy_pass http://127.0.0.1:9000;
# }
```

### 4. 数据库连接失败

**检查数据库配置：**

```bash
# 查看 .env 配置
cat /root/IoT_Smart_Hotel_System/backend/iot-hotel-backend/.env

# 检查数据库连接
mysql -u iot_user -p -h localhost hotel_system
```

### 5. 数据库表不存在

**检查数据库表：**

```sql
USE hotel_system;

-- 查看所有表
SHOW TABLES;

-- 检查 hotels 表
DESCRIBE hotels;

-- 检查 rooms 表
DESCRIBE rooms;
```

## 修复步骤

### 步骤 1：确保后端服务运行

```bash
# 进入后端目录
cd /root/IoT_Smart_Hotel_System/backend/iot-hotel-backend

# 安装依赖（如果需要）
npm install

# 启动服务
pm2 start ecosystem.config.js

# 或使用 npm
npm run start:prod
```

### 步骤 2：验证后端 API

```bash
# 测试酒店 API
curl http://127.0.0.1:9000/api/v1/hotels

# 测试房间 API
curl http://127.0.0.1:9000/api/v1/rooms

# 测试健康检查
curl http://127.0.0.1:9000/api/v1/health
```

### 步骤 3：检查 Nginx 配置

```bash
# 编辑配置
sudo vim /etc/nginx/sites-available/iot-hotel

# 确保有正确的代理配置
location /api {
    proxy_pass http://127.0.0.1:9000;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
}

# 测试并重启
sudo nginx -t
sudo systemctl restart nginx
```

### 步骤 4：测试完整流程

```bash
# 测试 Nginx 代理
curl http://localhost/api/v1/hotels
curl http://localhost/api/v1/rooms

# 查看 Nginx 错误日志
tail -n 50 /var/log/nginx/iot-hotel-error.log
```

## 常见错误及解决方案

### 错误 1: Connection refused

```
curl: (7) Failed to connect to 127.0.0.1 port 9000: Connection refused
```

**原因：** 后端服务未启动或端口未监听

**解决：**
```bash
pm2 start iot-hotel-backend
netstat -tuln | grep :9000
```

### 错误 2: 502 Bad Gateway

**原因：** Nginx 无法连接到后端

**解决：**
```bash
# 检查后端是否运行
pm2 status iot-hotel-backend

# 检查防火墙
ufw status

# 重启 Nginx
sudo systemctl restart nginx
```

### 错误 3: 500 Internal Server Error

**原因：** 后端服务返回错误

**解决：**
```bash
# 查看后端日志
pm2 logs iot-hotel-backend

# 检查数据库连接
mysql -u iot_user -p -h localhost hotel_system
```

## 环境变量检查
