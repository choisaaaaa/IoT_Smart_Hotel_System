# 前端构建与部署指南

## 问题诊断

**症状：** Nginx 配置正确，但访问首页显示空白或 500 错误

**原因：** `dist` 目录为空，前端项目未构建

## 解决方案

### 1. 构建前端项目

```bash
# 进入前端目录
cd /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web

# 安装依赖（如果还没安装）
npm install

# 构建生产版本
npm run build

# 检查构建结果
ls -la dist/
```

### 2. 验证构建输出

构建成功后，`dist` 目录应该包含：

```
dist/
├── assets/
│   ├── index-xxxx.js
│   ├── index-xxxx.css
│   └── ...
├── index.html
└── ...
```

### 3. 配置 Nginx

```bash
# 确保 Nginx 配置正确
sudo vim /etc/nginx/sites-available/iot-hotel

# 确认 root 路径
root /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web/dist;
```

### 4. 重启服务

```bash
# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx

# 验证访问
curl http://localhost
```

## 完整部署流程

```bash
# 1. 构建前端
cd /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web
npm install
npm run build

# 2. 设置权限
sudo chown -R www-data:www-data /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web/dist
sudo chmod -R 755 /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web/dist

# 3. 重启 Nginx
sudo systemctl restart nginx

# 4. 验证
curl http://localhost
```

## 常见问题

### Q: npm install 失败

```bash
# 检查 Node.js 版本
node -v

# 如果版本过低，更新 Node.js
# 参考：https://nodejs.org/zh-cn/download/
```

### Q: 构建失败

```bash
# 检查 TypeScript 配置
npx vue-tsc --noEmit

# 清理并重新构建
rm -rf dist
npm run build
```

### Q: 权限问题

```bash
# 确保 Nginx 用户有权限
sudo chown -R www-data:www-data /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web/dist
sudo chmod -R 755 /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web/dist
```

## 默认路由说明

根据路由配置：

```typescript
{
  path: '/',
  redirect: '/admin/dashboard'
}
```

**访问 `http://your-ip/` 会自动跳转到 `http://your-ip/admin/dashboard`**

如果需要修改默认首页，可以修改路由配置：

```typescript
// 修改为跳转到前台端
{
  path: '/',
  redirect: '/reception/dashboard'
}

// 或跳转到客户端
{
  path: '/',
  redirect: '/guest/booking'
}
```
