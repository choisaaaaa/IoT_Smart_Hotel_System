# 500 错误修复指南

## 问题诊断

根据错误日志：
```
stat() "/root/IoT_Smart_Hotel_System/frontend/iot-hotel-web/dist/" failed (13: Permission denied)
```

**原因：** Nginx 没有权限读取 `/root/` 目录下的文件

## 解决方案

### 方案一：移动前端目录到可访问位置（推荐）

```bash
# 1. 停止 Nginx
sudo systemctl stop nginx

# 2. 创建新的前端目录
sudo mkdir -p /var/www/iot-hotel-frontend

# 3. 复制前端文件
sudo cp -r /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web/dist/* /var/www/iot-hotel-frontend/

# 4. 设置权限
sudo chown -R www-data:www-data /var/www/iot-hotel-frontend
sudo chmod -R 755 /var/www/iot-hotel-frontend

# 5. 修改 Nginx 配置
sudo vim /etc/nginx/sites-available/iot-hotel

# 将 root 路径改为：
# root /var/www/iot-hotel-frontend;

# 6. 测试并重启
sudo nginx -t
sudo systemctl restart nginx
```

### 方案二：修改目录权限（简单但安全性较低）

```bash
# 1. 修改 root 目录权限
sudo chmod 755 /root
sudo chmod 755 /root/IoT_Smart_Hotel_System
sudo chmod 755 /root/IoT_Smart_Hotel_System/frontend
sudo chmod 755 /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web
sudo chmod 755 /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web/dist

# 2. 设置目录权限
sudo chmod 644 /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web/dist/*

# 3. 重启 Nginx
sudo systemctl restart nginx
```

### 方案三：使用 Nginx 用户访问（推荐）

```bash
# 1. 查看 Nginx 运行用户
sudo cat /etc/nginx/nginx.conf | grep user

# 通常是 www-data 或 nginx

# 2. 将 Nginx 用户添加到 root 组（谨慎操作）
sudo usermod -a -G root www-data

# 3. 修改目录权限
sudo chmod 750 /root/IoT_Smart_Hotel_System
sudo chmod 750 /root/IoT_Smart_Hotel_System/frontend
sudo chmod 750 /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web
sudo chmod 750 /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web/dist

# 4. 重启 Nginx
sudo systemctl restart nginx
```

## 避免问题再次发生

**最佳实践：**

1. **不要将前端文件放在 `/root/` 目录下**
   - `/root/` 是 root 用户的家目录，其他用户默认无法访问
   - 应该放在 `/var/www/` 或 `/opt/` 等公共目录

2. **正确的目录结构：**
   ```
   /var/www/
   └── iot-hotel-frontend/
       ├── index.html
       ├── assets/
       └── ...
   ```

3. **权限设置：**
   ```bash
   # 目录权限 755
   # 文件权限 644
   # 所有者 www-data:www-data
   ```

## 快速修复脚本

```bash
#!/bin/bash

echo "=== 修复 500 错误 ==="

# 1. 停止 Nginx
sudo systemctl stop nginx

# 2. 创建新目录
sudo mkdir -p /var/www/iot-hotel-frontend

# 3. 复制文件
echo "复制前端文件..."
sudo cp -r /root/IoT_Smart_Hotel_System/frontend/iot-hotel-web/dist/* /var/www/iot-hotel-frontend/

# 4. 设置权限
echo "设置权限..."
sudo chown -R www-data:www-data /var/www/iot-hotel-frontend
sudo chmod -R 755 /var/www/iot-hotel-frontend

# 5. 修改配置
echo "修改 Nginx 配置..."
sudo sed -i 's|/root/IoT_Smart_Hotel_System/frontend/iot-hotel-web/dist|/var/www/iot-hotel-frontend|g' /etc/nginx/sites-available/iot-hotel

# 6. 测试并重启
echo "测试配置..."
sudo nginx -t

echo "重启 Nginx..."
sudo systemctl restart nginx

# 7. 验证
echo "验证修复..."
curl -s http://localhost | head -20

echo "=== 修复完成 ==="
```
