# 后端与数据库版本更新对齐说明（简版覆盖更新）

## 1. 适用场景

适用于“直接覆盖更新”：

- 服务器代码落后，直接用当前仓库版本覆盖
- 数据库结构有差异，按项目 SQL 脚本补齐
- 不做复杂灰度，不做分批发布

## 2. 一次性覆盖更新步骤

### 2.1 拉取最新代码

```bash
cd /root/IoT_Smart_Hotel_System
git pull
```

### 2.2 更新后端并重启

```bash
cd /root/IoT_Smart_Hotel_System/backend/iot-hotel-backend
npm install
npm run build
pm2 restart iot-hotel-backend
pm2 status iot-hotel-backend
```

如果提示 `npm ci` 锁文件不同步，统一使用 `npm install` 覆盖安装即可。

### 2.3 执行数据库结构更新

按顺序执行项目内 SQL（已存在则跳过）：

```bash
mysql -u iot_user -p hotel_system < /root/IoT_Smart_Hotel_System/backend/iot-hotel-backend/database/migrations/add_auth_tables.sql
mysql -u iot_user -p hotel_system < /root/IoT_Smart_Hotel_System/backend/iot-hotel-backend/database/migrations/add_room_types.sql
mysql -u iot_user -p hotel_system < /root/IoT_Smart_Hotel_System/backend/iot-hotel-backend/database/migrations/add_room_types_v2.sql
mysql -u iot_user -p hotel_system < /root/IoT_Smart_Hotel_System/backend/iot-hotel-backend/database/migrations/update_devices_table.sql
```

如你有自己的增量 SQL，继续追加执行即可。

## 3. 更新后最小验证

### 3.1 服务状态

```bash
pm2 status iot-hotel-backend
curl http://127.0.0.1:9000/api/v1/health
```

### 3.2 核心接口

```bash
curl http://127.0.0.1:9000/api/v1/rooms
curl "http://127.0.0.1:9000/api/v1/bookings?pageSize=5"
```

### 3.3 关键业务点

- 前台“新建预订”可成功
- 不再出现 `Field 'hotel_id' doesn't have a default value`
- 入住页可打开，不出现 mounted 未捕获异常

## 4. 出问题时快速回滚

```bash
cd /root/IoT_Smart_Hotel_System
git reset --hard HEAD~1
cd backend/iot-hotel-backend
npm install
npm run build
pm2 restart iot-hotel-backend
```

如果数据库也改坏，再恢复你自己的备份 SQL。

## 5. 开放 MySQL 到公网（最小可用）

当前项目的 MySQL 容器已映射 `3306:3306`，还需要做三件事：开数据库账号、开系统防火墙、开云安全组。

### 5.1 创建公网访问账号（不要用 root）

```sql
CREATE USER IF NOT EXISTS 'iot_remote'@'%' IDENTIFIED BY 'StrongPass_2026!';
GRANT ALL PRIVILEGES ON iot_hotel_system.* TO 'iot_remote'@'%';
FLUSH PRIVILEGES;
```

如只允许固定办公 IP（推荐）：

```sql
CREATE USER IF NOT EXISTS 'iot_remote'@'你的公网IP' IDENTIFIED BY 'StrongPass_2026!';
GRANT ALL PRIVILEGES ON iot_hotel_system.* TO 'iot_remote'@'你的公网IP';
FLUSH PRIVILEGES;
```

### 5.2 开放服务器防火墙 3306

Ubuntu(UFW)：

```bash
sudo ufw allow from 你的公网IP to any port 3306 proto tcp
sudo ufw status
```

CentOS/RHEL(firewalld)：

```bash
sudo firewall-cmd --permanent --add-rich-rule='rule family="ipv4" source address="你的公网IP" port protocol="tcp" port="3306" accept'
sudo firewall-cmd --reload
sudo firewall-cmd --list-all
```

### 5.3 开放云厂商安全组

- 入站规则新增：TCP 3306
- 来源 IP：`你的公网IP/32`
- 不要直接放开 `0.0.0.0/0`

### 5.4 连通性验证

```bash
mysql -h 服务器公网IP -P 3306 -u iot_remote -p iot_hotel_system
```
