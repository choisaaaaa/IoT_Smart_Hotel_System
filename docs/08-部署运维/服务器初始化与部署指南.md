## 5. 安装 MySQL

### 5.1 安装 MySQL 服务器

```bash
# 安装 MySQL
sudo apt install -y mysql-server

# 启动 MySQL 服务
sudo systemctl start mysql
sudo systemctl enable mysql

# 验证安装
sudo systemctl status mysql
```

### 5.2 配置 MySQL 远程访问

```bash
# 编辑 MySQL 配置文件
sudo vim /etc/mysql/mysql.conf.d/mysqld.cnf

# 找到 bind-address 行，修改为：
bind-address = 0.0.0.0

# 保存并退出
# :wq

# 重启 MySQL
sudo systemctl restart mysql

# 验证监听端口
sudo ss -tlnp | grep mysql
```

**预期输出**：
```
LISTEN 0 80 0.0.0.0:3306 0.0.0.0:* mysql
```

### 5.3 创建数据库和用户

```bash
# 登录 MySQL
sudo mysql -u root -p

# 输入空密码（直接回车）

# 创建数据库
CREATE DATABASE hotel_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 创建用户
CREATE USER 'iot_user'@'%' IDENTIFIED BY 'iot2026.';

# 授权
GRANT ALL PRIVILEGES ON hotel_system.* TO 'iot_user'@'%';

# 刷新权限
FLUSH PRIVILEGES;

# 退出
EXIT;
```

## 6. 安装 MQTT Broker

### 6.1 安装 Mosquitto

```bash
# 添加 Mosquitto 仓库
sudo apt install -y software-properties-common
sudo add-apt-repository ppa:mosquitto-mosquitto/mosquitto-ppa
sudo apt update

# 安装 Mosquitto
sudo apt install -y mosquitto mosquitto-clients

# 启动 Mosquitto 服务
sudo systemctl start mosquitto
sudo systemctl enable mosquitto

# 验证安装
mosquitto --version
```

### 6.2 配置 Mosquitto

```bash
# 编辑配置文件
sudo vim /etc/mosquitto/mosquitto.conf

# 添加以下配置：
listener 1883
allow_anonymous false
password_file /etc/mosquitto/passwd

# 保存并退出
# :wq

# 创建用户密码文件
sudo touch /etc/mosquitto/passwd
sudo chown mosquitto:mosquitto /etc/mosquitto/passwd

# 添加用户（输入密码：IotHotel2026）
sudo mosquitto_passwd -c /etc/mosquitto/passwd iot_user

# 重启 Mosquitto
sudo systemctl restart mosquitto

# 验证监听端口
sudo ss -tlnp | grep mosquitto
```

**预期输出**：
```
LISTEN 0 128 0.0.0.0:1883 0.0.0.0:* mosquitto
```

cd ~/iot-hotel-system/IoT_Smart_Hotel_System/backend/iot-hotel-backend

**环境变量配置**：

MQTT_USERNAME=iot_user

WS_PATH=/ws
WS_HEARTBEAT_INTERVAL=30000

# 限流配置

RATE_LIMIT_MAX_REQUESTS=100

### 7.3 构建项目

```bash

```

### 7.4 配置 PM2

```bash
# 创建 PM2 配置文件
vim ecosystem.config.js
```

**ecosystem.config.js 内容**：

```javascript
module.exports = {
  apps: [{
    name: 'iot-hotel-backend',
    script: 'dist/server.js',
    instances: 1,
    autorestart: true,
    watch: false,
    max_memory_restart: '1G',
    env: {
      NODE_ENV: 'production'
    },
    out_file: './logs/out.log',
    error_file: './logs/error.log',
    merge_logs: true,
    log_date_format: 'YYYY-MM-DD HH:mm:ss'
  }]
};
```

## 9. 配置 Nginx

### 9.1 安装 Nginx

```bash
# 安装 Nginx
sudo apt install -y nginx

# 启动 Nginx
sudo systemctl start nginx
sudo systemctl enable nginx

# 验证安装
nginx -v
```

### 9.2 配置反向代理

```bash
# 创建 Nginx 配置
sudo vim /etc/nginx/sites-available/iot-hotel
```

**配置内容**：

```nginx
# HTTP 服务器
server {
    listen 80;
    server_name 8.134.166.69;

    # 后端 API 代理
    location /api {
        proxy_pass http://127.0.0.1:9000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket 代理
    location /ws {
        proxy_pass http://127.0.0.1:9000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 86400;
    }

    # 前端静态文件
    location / {
        root /root/iot-hotel-system/IoT_Smart_Hotel_System/frontend/iot-hotel-web/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf)$ {
        expires 7d;
        add_header Cache-Control "public, immutable";
    }

    # 访问日志
    access_log /var/log/nginx/iot-hotel-access.log;
    error_log /var/log/nginx/iot-hotel-error.log;
}
```

### 9.3 启用配置

```bash
# 创建软链接
sudo ln -s /etc/nginx/sites-available/iot-hotel /etc/nginx/sites-enabled/

# 删除默认配置
sudo rm /etc/nginx/sites-enabled/default

# 测试配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
```

## 10. 配置防火墙

### 10.1 配置 UFW 防火墙

```bash
# 安装 UFW
sudo apt install -y ufw

# 设置默认策略
sudo ufw default deny incoming
sudo ufw default allow outgoing

# 允许必需端口
sudo ufw allow 22/tcp      # SSH
sudo ufw allow 80/tcp      # HTTP
sudo ufw allow 443/tcp     # HTTPS
sudo ufw allow 1883/tcp    # MQTT

# 启用防火墙
sudo ufw enable

# 查看状态
sudo ufw status verbose
```

**预期输出**：
```
Status: active

To                         Action      From
--                         ------      ----
22/tcp                     ALLOW       Anywhere
80/tcp                     ALLOW       Anywhere
443/tcp                    ALLOW       Anywhere
1883/tcp                   ALLOW       Anywhere
22/tcp (v6)                ALLOW       Anywhere (v6)
80/tcp (v6)                ALLOW       Anywhere (v6)
443/tcp (v6)               ALLOW       Anywhere (v6)
1883/tcp (v6)              ALLOW       Anywhere (v6)
```

### 10.2 配置 MySQL 仅内网访问

```bash
# 仅允许内网 IP 访问 MySQL
sudo ufw allow from 10.0.0.0/8 to any port 3306
sudo ufw allow from 172.16.0.0/12 to any port 3306
sudo ufw allow from 192.168.0.0/16 to any port 3306

# 查看状态
sudo ufw status
```
