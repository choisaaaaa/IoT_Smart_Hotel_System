# 防火墙配置检查命令

## 🔍 查看防火墙状态

### 1. 检查 UFW 防火墙状态

```bash
# 查看防火墙状态
sudo ufw status

# 查看详细状态
sudo ufw status verbose

# 查看规则编号
sudo ufw status numbered
```

**正常输出示例**：
```
Status: active

To                         Action      From
--                         ------      ----
22/tcp                     ALLOW       Anywhere
80/tcp                     ALLOW       Anywhere
443/tcp                    ALLOW       Anywhere
1883/tcp                   ALLOW       Anywhere
3306/tcp                   ALLOW       10.0.0.0/8
22/tcp (v6)                ALLOW       Anywhere (v6)
80/tcp (v6)                ALLOW       Anywhere (v6)
443/tcp (v6)               ALLOW       Anywhere (v6)
1883/tcp (v6)              ALLOW       Anywhere (v6)
```

### 2. 检查云服务商安全组配置

**阿里云/腾讯云安全组检查**：

登录云服务商控制台，检查安全组规则：

| 端口 | 协议 | 授权对象 | 说明 |
|------|------|---------|------|
| 22 | TCP | 0.0.0.0/0 | SSH（建议限制IP） |
| 80 | TCP | 0.0.0.0/0 | HTTP |
| 443 | TCP | 0.0.0.0/0 | HTTPS |
| 1883 | TCP | 0.0.0.0/0 | MQTT |
| 3306 | TCP | 10.0.0.0/8 | MySQL（仅内网） |

## 🛠️ 常用防火墙命令

### 1. 添加规则

```bash
# 允许 SSH
sudo ufw allow 22/tcp

# 允许 HTTP
sudo ufw allow 80/tcp

# 允许 HTTPS
sudo ufw allow 443/tcp

# 允许 MQTT
sudo ufw allow 1883/tcp

# 允许 MySQL（仅内网）
sudo ufw allow from 10.0.0.0/8 to any port 3306
sudo ufw allow from 172.16.0.0/12 to any port 3306
sudo ufw allow from 192.168.0.0/16 to any port 3306

# 允许特定 IP
sudo ufw allow from 192.168.1.100
```

### 2. 删除规则

```bash
# 删除规则（按规则编号）
sudo ufw delete 5

# 删除规则（按规则内容）
sudo ufw delete allow 80/tcp
```

### 3. 重置防火墙

```bash
# 重置所有规则
sudo ufw reset

# 关闭防火墙
sudo ufw disable

# 开启防火墙
sudo ufw enable
```

## 📊 检查端口监听状态

```bash
# 查看所有监听端口
sudo netstat -tlnp

# 或使用 ss（推荐）
sudo ss -tlnp

# 查看特定端口
sudo ss -tlnp | grep :80
```

**正常输出示例**：
```
State      Recv-Q Send-Q Local Address:Port   Peer Address:Port
LISTEN     0      128          0.0.0.0:80          0.0.0.0:*
LISTEN     0      128          0.0.0.0:443         0.0.0.0:*
LISTEN     0      128          0.0.0.0:1883        0.0.0.0:*
LISTEN     0      80         127.0.0.1:3306        0.0.0.0:*
```

## 🔧 检查 Nginx 服务

```bash
# 检查 Nginx 状态
sudo systemctl status nginx

# 查看 Nginx 监听端口
sudo ss -tlnp | grep nginx

# 测试 Nginx 配置
sudo nginx -t

# 重启 Nginx
sudo systemctl restart nginx
```

## 🚀 快速检查脚本

```bash
#!/bin/bash

echo "=== 防火墙状态 ==="
sudo ufw status verbose

echo -e "\n=== 监听端口 ==="
sudo ss -tlnp | grep -E "(80|443|1883|3306|9000)"

echo -e "\n=== Nginx 状态 ==="
sudo systemctl status nginx --no-pager

echo -e "\n=== 测试 HTTP 访问 ==="
curl -s -o /dev/null -w "%{http_code}" http://localhost

echo -e "\n=== 测试 MQTT 访问 ==="
# 需要安装 mosquitto-clients
mosquitto_pub -h localhost -p 1883 -t "test" -m "test" 2>/dev/null && echo "MQTT OK" || echo "MQTT Failed"
```

## ⚠️ 常见问题

### 1. 防火墙阻止连接

**问题**：无法访问服务

**解决方案**：
```bash
# 检查防火墙状态
sudo ufw status

# 添加允许规则
sudo ufw allow 80/tcp
sudo ufw allow 1883/tcp

# 重启防火墙
sudo ufw reload
```

### 2. 端口未监听

**问题**：服务未启动

**解决方案**：
```bash
# 检查服务状态
sudo systemctl status nginx
sudo systemctl status mosquitto

# 启动服务
sudo systemctl start nginx
sudo systemctl start mosquitto

# 设置开机自启
sudo systemctl enable nginx
sudo systemctl enable mosquitto
```

### 3. 云服务商安全组阻止

**问题**：防火墙开放但无法访问

**解决方案**：
- 登录云服务商控制台
- 检查安全组规则
- 添加入站规则
