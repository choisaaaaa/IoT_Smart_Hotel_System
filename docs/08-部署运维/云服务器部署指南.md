## 2. SSH远程连接

### 2.1 获取服务器信息

购买完成后，获取以下信息：

- **公网IP**: 例如 `47.95.200.100`
- **用户名**: 默认 `ubuntu` (Ubuntu系统)
- **密码**: 创建时设置的密码，或使用密钥登录

### 2.2 Windows SSH连接

**方法1: 使用PowerShell**

```powershell
# 打开PowerShell，输入：
ssh ubuntu@47.95.200.100
```

**方法2: 使用PuTTY**

1. 下载 [PuTTY](https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html)
2. 输入主机IP：`47.95.200.100`
3. 端口：`22`
4. 连接类型：`SSH`
5. 点击"Open"

### 2.3 macOS/Linux SSH连接

```bash
ssh ubuntu@47.95.200.100
```

首次连接会提示确认指纹，输入 `yes` 继续。

## 3. 系统初始化

### 3.1 更新系统

```bash
# 更新软件包列表
sudo apt update

# 升级已安装的软件包
sudo apt upgrade -y

# 安装常用工具
sudo apt install -y curl wget git vim htop net-tools
```

### 3.2 创建新用户（安全最佳实践）

```bash
# 创建新用户
sudo adduser yourusername

# 添加到sudo组
sudo usermod -aG sudo yourusername

# 切换到新用户
su - yourusername
```

### 3.3 配置SSH密钥登录（推荐）

**本地生成密钥**（Windows PowerShell）：

```powershell
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
# 按提示操作，直接回车使用默认路径
```

**复制公钥到服务器**：

```bash
# 方法1: 使用ssh-copy-id
ssh-copy-id yourusername@47.95.200.100

# 方法2: 手动复制
# 在本地读取公钥
cat ~/.ssh/id_rsa.pub

# 在服务器创建authorized_keys
mkdir -p ~/.ssh
chmod 700 ~/.ssh
echo "你的公钥内容" >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

**禁用密码登录**（可选，提高安全性）：

```bash
sudo vim /etc/ssh/sshd_config
# 修改以下配置：
# PasswordAuthentication no
# PubkeyAuthentication yes

# 重启SSH服务
sudo systemctl restart sshd
```

## 5. 安装MySQL数据库

### 5.1 安装MySQL

```bash
# 安装MySQL服务器
sudo apt install -y mysql-server

# 启动MySQL服务
sudo systemctl start mysql
sudo systemctl enable mysql

# 运行安全配置脚本
sudo mysql_secure_installation

# 按提示配置：
# 1. Validate password component? (y/N) -> N
# 2. New password -> 设置root密码
# 3. Remove anonymous users? (Y/n) -> Y
# 4. Disallow root login remotely? (Y/n) -> N (允许远程连接)
# 5. Remove test database? (Y/n) -> Y
# 6. Reload privilege tables? (Y/n) -> Y
```

### 5.2 配置MySQL远程访问

```bash
# 编辑MySQL配置文件
sudo vim /etc/mysql/mysql.conf.d/mysqld.cnf

# 修改以下配置：
bind-address = 0.0.0.0  # 允许所有IP连接

# 重启MySQL服务
sudo systemctl restart mysql

# 登录MySQL
sudo mysql -u root -p

# 创建数据库
CREATE DATABASE hotel_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# 创建用户并授权
CREATE USER 'iot_user'@'%' IDENTIFIED BY '你的密码';
GRANT ALL PRIVILEGES ON hotel_system.* TO 'iot_user'@'%';
FLUSH PRIVILEGES;

# 退出
EXIT;
```

### 5.3 配置防火墙允许MySQL访问（可选）

```bash
# 仅允许内网IP访问MySQL（推荐）
sudo ufw allow from 10.0.0.0/8 to any port 3306
sudo ufw allow from 172.16.0.0/12 to any port 3306
sudo ufw allow from 192.168.0.0/16 to any port 3306
```

## 6. 安装MQTT Broker

### 6.1 安装Mosquitto

```bash
# 添加Mosquitto仓库
sudo apt install -y software-properties-common
sudo add-apt-repository ppa:mosquitto-mosquitto/mosquitto-ppa
sudo apt update

# 安装Mosquitto
sudo apt install -y mosquitto mosquitto-clients

# 启动Mosquitto服务
sudo systemctl start mosquitto
sudo systemctl enable mosquitto

# 验证安装
mosquitto --version
```

### 6.2 配置Mosquitto

```bash
# 编辑配置文件
sudo vim /etc/mosquitto/mosquitto.conf

# 添加以下配置：
listener 1883
allow_anonymous false
password_file /etc/mosquitto/passwd

# 创建用户密码文件
sudo touch /etc/mosquitto/passwd
sudo chown mosquitto:mosquitto /etc/mosquitto/passwd

# 添加用户（示例：iot_user）
sudo mosquitto_passwd -c /etc/mosquitto/passwd iot_user
# 输入密码：IotHotel2026

# 重启Mosquitto服务
sudo systemctl restart mosquitto
```

### 6.3 测试MQTT服务

```bash
# 订阅测试主题
mosquitto_sub -h localhost -p 1883 -u "iot_user" -P "IotHotel2026" -t "hotel/test"

# 发布测试消息（新打开一个终端）
mosquitto_pub -h localhost -p 1883 -u "iot_user" -P "IotHotel2026" -t "hotel/test" -m "Hello from server"
```

## 8. 配置Nginx反向代理

### 8.1 安装Nginx

```bash
# 安装Nginx
sudo apt install -y nginx

# 启动Nginx

sudo systemctl enable nginx

```

### 8.2 配置反向代理（使用IP地址）

如果你**只有IP地址，没有域名**，使用以下配置：

```bash
# 创建配置文件
sudo vim /etc/nginx/sites-available/iot-hotel
```

**配置内容**（使用IP地址）：

```nginx
# HTTP服务器（直接使用IP访问）
server {
    listen 80;
    server_name 8.134.166.69;  # 替换为你的服务器IP
    
    # WebSocket支持
    location /ws {
        proxy_pass http://127.0.0.1:9000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 86400;
    }
    
    # API代理
    location /api {
        proxy_pass http://127.0.0.1:9000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    
    # 根路径
    location / {
        proxy_pass http://127.0.0.1:9000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

**配置内容**（支持域名和IP）：


## 9. 配置防火墙

### 9.1 配置UFW防火墙

```bash
# 安装UFW
sudo apt install -y ufw

# 设置默认策略
sudo ufw default deny incoming
sudo ufw default allow outgoing

# 允许必需端口
sudo ufw allow 22/tcp      # SSH
sudo ufw allow 80/tcp      # HTTP
sudo ufw allow 443/tcp     # HTTPS
sudo ufw allow 1883/tcp    # MQTT

# 启用防火墙
sudo ufw enable

# 查看状态
sudo ufw status verbose
```

## 12. 常见问题

### 12.1 端口冲突

**问题**: 端口已被占用

**解决方案**：

```bash
# 查看端口占用
sudo lsof -i :9000

# 杀死进程
sudo kill -9 <PID>

# 或修改端口
vim .env
# PORT=9001
```

### 12.2 数据库连接失败

**问题**: `ER_ACCESS_DENIED_ERROR`

**解决方案**：

```bash
# 检查MySQL用户权限
sudo mysql -u root -p
USE mysql;
SELECT User, Host FROM user WHERE User='iot_user';
EXIT;

# 重新授权
GRANT ALL PRIVILEGES ON hotel_system.* TO 'iot_user'@'%';
FLUSH PRIVILEGES;
```

### 12.3 MQTT连接失败

**问题**: `Connection refused`

**解决方案**：

```bash
# 检查Mosquitto服务状态
sudo systemctl status mosquitto

# 查看日志
sudo tail -f /var/log/mosquitto/mosquitto.log

# 检查配置
sudo cat /etc/mosquitto/mosquitto.conf

# 重启服务
sudo systemctl restart mosquitto
```

### 12.4 Nginx 502 Bad Gateway

**问题**: 后端服务未启动

**解决方案**：

```bash
# 检查后端服务状态
pm2 status

# 查看后端日志
pm2 logs iot-hotel-backend

# 重启后端服务
pm2 restart iot-hotel-backend

# 检查Nginx配置
sudo nginx -t
sudo systemctl restart nginx
```

### 12.5 防火墙阻止连接

**问题**: 无法访问服务

**解决方案**：

```bash
# 检查UFW状态
sudo ufw status

# 添加规则
sudo ufw allow 9000/tcp
```
