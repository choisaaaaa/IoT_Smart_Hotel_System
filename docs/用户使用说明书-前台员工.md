# 智慧酒店物联网控制系统 - 前台员工使用说明书

## 📋 系统概述

智慧酒店物联网控制系统是一个基于现代 Web 技术栈的综合管理平台，旨在为酒店提供智能化、自动化的运营管理解决方案。作为前台员工，您主要负责酒店的日常运营，包括办理入住/退房、处理工单、管理预订等。

## 🚀 登录系统

1. **访问登录页面**：打开浏览器，输入系统 URL
2. **输入账号信息**：
   - 用户名：前台员工账号
   - 密码：前台员工密码
3. **点击登录**：进入前台管理界面

## 🎯 核心功能

### 1. 前台总览

- **功能入口**：左侧导航栏 → 前台总览
- **功能说明**：
  - 查看酒店实时运营数据
  - 查看今日预订、入住、退房情况
  - 了解酒店整体运行状态

### 2. 接待中心

- **功能入口**：左侧导航栏 → 接待中心
- **功能说明**：
  - 查看可视化房态图
  - **办理入住**：点击空闲房间，填写住客信息，完成入住办理
  - **办理退房**：点击在住房间，完成退房手续
  - **现场打折授权**：在办理入住时，通过经理账号输入密码进行实时打折授权

### 3. 主控设备管理

- **功能入口**：左侧导航栏 → 主控设备管理
- **功能说明**：
  - 查看酒店主要设备的状态
  - 控制公共区域设备
  - 查看设备运行情况

### 4. 预订管理

- **功能入口**：左侧导航栏 → 预订管理
- **功能说明**：
  - 查看预订列表
  - **处理预订**：确认或取消预订
  - **查看预订详情**：查看预订的详细信息
  - **修改预订**：修改预订信息

### 5. 客房余量

- **功能入口**：左侧导航栏 → 客房余量
- **功能说明**：
  - 查看实时客房余量
  - 了解房间状态分布
  - 查看不同房型的可用数量

### 6. 工单处理

- **功能入口**：左侧导航栏 → 工单处理
- **功能说明**：
  - 查看报修工单列表
  - **处理报修**：分配工单给维修人员
  - **更新工单状态**：标记工单为已处理
  - **查看工单详情**：查看工单的详细信息

### 7. 客房送物

- **功能入口**：左侧导航栏 → 客房送物
- **功能说明**：
  - 查看送物订单列表
  - **处理送物请求**：分配任务给服务人员
  - **更新订单状态**：标记订单为已完成
  - **查看订单详情**：查看订单的详细信息

### 8. 语音通话

- **功能入口**：左侧导航栏 → 语音通话
- **功能说明**：
  - **发起通话**：选择房间，发起语音通话
  - **接听来电**：接收并接听客房来电
  - **查看通话记录**：查看历史通话记录

### 9. 环境监测

- **功能入口**：左侧导航栏 → 环境监测
- **功能说明**：
  - 查看各楼层、房间的温湿度及烟雾报警状态
  - 查看环境数据趋势图
  - 接收环境异常报警

### 10. 价格日历

- **功能入口**：左侧导航栏 → 价格日历
- **功能说明**：
  - 查看不同日期的房型价格
  - 调整房间库存
  - 查看价格趋势

### 11. 优惠券管理

- **功能入口**：左侧导航栏 → 优惠券管理
- **功能说明**：
  - 查看优惠券列表
  - **发放优惠券**：向住客发放优惠券
  - **查看优惠券使用情况**：了解优惠券的使用情况

### 12. 账单报表

- **功能入口**：左侧导航栏 → 账单报表
- **功能说明**：
  - 查看酒店营收报表
  - 查看账单明细
  - 导出报表数据

## 🔒 权限说明

作为前台员工，您拥有以下权限：

- 办理入住/退房手续
- 处理工单和送物请求
- 管理预订
- 控制公共区域设备
- 查看酒店运营数据

## ❓ 常见问题

### 1. 无法登录系统

**Q: 无法登录系统**
A: 检查账号和密码是否正确，确保网络连接正常。如忘记密码，请联系酒店管理员。

### 2. 办理入住失败

**Q: 点击「办理入住」按钮后系统无反应**
A: 检查住客信息是否完整，网络连接是否正常，如问题持续，请联系技术支持。

### 3. 语音通话失败

**Q: 发起语音通话后无响应**
A: 检查网络连接是否正常，设备是否在线，如问题持续，请联系技术支持。

### 4. 工单处理不更新

**Q: 更新工单状态后，状态未改变**
A: 检查网络连接是否正常，尝试刷新页面，如问题持续，请联系技术支持。
