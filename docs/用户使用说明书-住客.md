# 智慧酒店物联网控制系统 - 住客使用说明书

## 📋 系统概述

智慧酒店物联网控制系统是一个基于现代 Web 技术栈的综合管理平台，旨在为酒店提供智能化、自动化的运营管理解决方案。作为住客，您可以通过系统享受智能客房控制、AI 语音助手、在线服务等便捷功能。

## 🚀 访问系统

### 1. 客房预订

1. **访问预订页面**：打开浏览器，输入酒店预订 URL
2. **选择日期和房型**：选择入住和退房日期，选择合适的房型
3. **填写预订信息**：填写个人信息、联系方式等
4. **提交订单**：确认信息后提交订单
5. **支付**：选择支付方式，完成支付

### 2. 在线办理入住

1. **访问在线入住页面**：打开浏览器，输入在线入住 URL
2. **验证预订**：输入预订信息（如预订号、手机号）进行验证
3. **提交身份信息**：上传身份证照片，填写个人信息
4. **完成预入住**：系统确认后完成预入住

### 3. 智能客房控制

1. **访问客房服务页面**：打开浏览器，输入客房服务 URL
2. **验证身份**：输入房间号和验证码（或扫码进入）
3. **控制设备**：
   - 灯光：调整亮度、颜色
   - 空调：调整温度、模式
   - 窗帘：控制开关、开合程度
   - 情景模式：选择睡眠、娱乐、阅读等模式

## 🎯 核心功能

### 1. 客房预订

- **功能入口**：首页 → 客房预订
- **功能说明**：
  - 浏览酒店和房型信息
  - 选择入住和退房日期
  - 填写预订信息并提交
  - 支付定金或全款

### 2. 在线办理入住

- **功能入口**：首页 → 在线办理入住
- **功能说明**：
  - 输入预订信息进行验证
  - 提交身份信息
  - 完成预入住
  - 查看入住信息

### 3. 智能客房控制

- **功能入口**：首页 → 客房服务
- **功能说明**：
  - 图形化控制灯光、空调、窗帘
  - 选择情景模式（睡眠、娱乐、阅读）
  - 查看房间状态

### 4. AI 语音管家

- **功能入口**：客房服务页面 → AI 管家图标
- **功能说明**：
  - 发送文字或语音指令
  - 获得 AI 管家的响应
  - 控制设备或获取酒店信息
  - 发起服务请求

### 5. 我的订单

- **功能入口**：首页 → 我的订单
- **功能说明**：
  - 查看历史订单
  - 了解订单状态
  - 发起续住申请
  - 查看订单详情

### 6. 个人中心

- **功能入口**：首页 → 个人中心
- **功能说明**：
  - 查看会员等级、积分、优惠券
  - 管理个人信息
  - 查看消费足迹
  - 绑定支付方式

### 7. 在线续住

- **功能入口**：我的订单 → 续住按钮
- **功能说明**：
  - 选择续住天数
  - 查看续住价格（含会员折扣、优惠券抵扣、积分抵扣）
  - 确认并支付
  - 完成续住

### 8. 服务请求

- **功能入口**：客房服务页面 → 服务请求
- **功能说明**：
  - 发起送物请求
  - 提交报修申请
  - 查看服务请求状态

## ❓ 常见问题

### 1. 无法访问预订页面

**Q: 无法访问预订页面**
A: 检查网络连接是否正常，尝试使用其他浏览器，如问题持续，请联系酒店前台。

### 2. 在线入住失败

**Q: 在线入住时验证失败**
A: 检查预订信息是否正确，确保预订未过期，如问题持续，请联系酒店前台。

### 3. 无法控制客房设备

**Q: 发送控制指令后设备无响应**
A: 检查网络连接是否正常，设备是否在线，如问题持续，请联系酒店前台。

### 4. AI 管家无响应

**Q: 发送指令后 AI 管家无响应**
A: 检查网络连接是否正常，尝试重新发送指令，如问题持续，请联系酒店前台。

### 5. 续住申请失败

**Q: 发起续住申请后系统无响应**
A: 检查网络连接是否正常，确保预订未过期，如问题持续，请联系酒店前台。
