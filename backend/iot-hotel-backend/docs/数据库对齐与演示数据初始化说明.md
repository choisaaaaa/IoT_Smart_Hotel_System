## 4. 复用方式

如需重置演示数据，可在后端目录执行：

```bash
node scripts/seed-demo-data.js
```

如需重新做结构对齐，可执行：

```bash
node scripts/apply-align-v260.js
```

## 5. 注意事项

- 本说明对应数据库：`iot_hotel_system`
- `.env` 中数据库连接需指向目标环境
- 在生产环境使用前，请替换测试账号密码并收敛公网访问权限
