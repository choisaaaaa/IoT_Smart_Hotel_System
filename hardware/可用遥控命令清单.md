# 智慧酒店硬件可用遥控命令清单

本文档只列出**当前代码已实现且可执行**的 MQTT 遥控命令（客房端 / 楼控端 / 前台端）。

## 1. 通用下发规范

- 命令主题前缀：`hotel/device/command`
- 通用主题格式：
  - 客房：`hotel/device/command/room/{device_id}`
  - 楼控：`hotel/device/command/floor/{device_id}`
  - 前台：`hotel/device/command/front_desk/{device_id}`
- 建议通用字段：
  - `command_id`：数字，命令流水号
  - `device_id`：目标设备 ID（如 `room_301`）
  - `command_type`：命令字
  - `command_value`：可选，命令参数（数字/字符串/对象）
  - `timestamp`：ISO8601 时间
  - `signature`：签名（如启用鉴权）

最小示例：

```json
{
  "command_id": 10001,
  "device_id": "room_301",
  "command_type": "light_on",
  "timestamp": "2026-04-24T10:00:00.000Z"
}
```

## 2. 客房端（room_terminal）可用命令

主题：`hotel/device/command/room/{device_id}`

### 2.1 基础设备控制

- `light_on`：开灯
- `light_off`：关灯
- `air_on`：空调/插座继电器开
- `air_off`：空调/插座继电器关
- `curtain_open`：开窗帘
- `curtain_close`：关窗帘
- `door_unlock`：开锁（含自动回锁逻辑）
- `door_lock`：手动上锁

### 2.2 新增参数调节

- `set_ac_temp` / `ac_set_temp` / `ac_temp`
  - 参数：`value` 或 `command_value`
  - 范围：`16 ~ 30`
- `set_light_brightness` / `light_brightness`
  - 参数：`value` 或 `command_value`
  - 范围：`0 ~ 100`
- `set_volume` / `volume_set` / `volume`
  - 参数：`value` 或 `command_value`
  - 范围：`0 ~ 100`

示例（空调温度）：

```json
{
  "command_id": 10002,
  "device_id": "room_301",
  "command_type": "set_ac_temp",
  "command_value": 26
}
```

示例（亮度）：

```json
{
  "command_id": 10003,
  "device_id": "room_301",
  "command_type": "set_light_brightness",
  "command_value": 35
}
```

示例（音量）：

```json
{
  "command_id": 10004,
  "device_id": "room_301",
  "command_type": "set_volume",
  "command_value": 70
}
```

### 2.3 场景命令（已与硬件对齐）

- 主场景：
  - `scene_welcome`
  - `scene_reading`
  - `scene_night`
  - `scene_sleep`
  - `scene_next`
- 场景别名：
  - `light_scene_welcome` / `scene_home` -> 欢迎场景
  - `light_scene_reading` -> 阅读场景
  - `light_scene_night` -> 夜间场景
  - `light_scene_sleep` / `scene_leave` -> 睡眠场景

### 2.4 广播警报

- `broadcast_alarm` / `alarm_broadcast`
  - 行为：通过喇叭播放内置警报音型

### 2.5 房卡相关（已实现）

- `issue_card`
- `write_blank_card`
- `verify_card`
- `swipe_card`

### 2.6 已禁用（客房端不再支持通话）

以下命令会被拒绝并回执“通话功能已禁用”：

- `incoming_call`
- `hangup_call`
- `answer_call`
- `reject_call`
- `call_answered`

## 3. 楼控端（floor_controller）可用命令

主题：`hotel/device/command/floor/{device_id}`

- `light_on`：走廊照明开
- `light_off`：走廊照明关
- `broadcast_alarm`（兼容 `broadcast_start`）：触发广播警报（蜂鸣器鸣叫）
- `broadcast_stop`：停止广播警报流程（当前无持续动作，做语义结束）
- `floor_reset`：执行复位动作（继电器弹一次 + 蜂鸣器短鸣三声）

示例（楼控复位）：

```json
{
  "command_id": 20001,
  "device_id": "floor_03",
  "command_type": "floor_reset"
}
```

---

## 4. 前台端（front_desk_terminal）可用命令

主题：`hotel/device/command/front_desk/{device_id}`

### 4.1 卡务

- `issue_card`
- `write_blank_card`
- `verify_card`
- `swipe_card`

### 4.2 新增报警

- `alarm_trigger` / `front_alarm`
  - 行为：触发前台报警事件上报并蜂鸣器提示

示例（前台报警）：

```json
{
  "command_id": 30001,
  "device_id": "front_desk_01",
  "command_type": "alarm_trigger"
}
```

---

## 5. 软件侧推荐下发命令字（与当前硬件一致）

为避免“发了不执行”，建议统一使用下列命令字：

- 客房：`light_on/off`、`air_on/off`、`curtain_open/close`、`door_unlock/lock`、
  `set_ac_temp`、`set_light_brightness`、`set_volume`、`scene_*`、`broadcast_alarm`
- 楼控：`light_on/off`、`broadcast_alarm`、`broadcast_stop`、`floor_reset`
- 前台：`issue_card`、`write_blank_card`、`verify_card`、`swipe_card`、`alarm_trigger`

---

## 6. 兼容与联调说明

- 新旧命令混用时，优先以本清单为准。
- 若后端/前端需要兼容历史命令（如 `light + on/off` 组合），应在软件层做映射后再下发到硬件。
- 每次固件升级后，建议同步更新本文档。
