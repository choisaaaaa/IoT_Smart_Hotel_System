# 智慧酒店物联网控制系统 - 硬件工程 (Hardware)

本目录包含了智慧酒店物联网边缘侧（客房端、前台端、楼控端）的全部设备固件源码及工程配置。

## 🎯 开发人员导读 (Quick Start)

为确保工程环境一致性与开发规范，请开发人员按以下顺序查阅相关文档并进行初始配置：

1. **熟悉整体架构**：请参阅 `docs/硬件架构与设计基线_v1.0.md`，了解系统工作原理、通信链路设计与全局引脚分配 (Pinmap)。
2. **部署开发环境**：请依据 `docs/硬件开发环境配置与协同指南_v1.0.md`，完成 VSCode 与 ESP-IDF 开发框架的标准安装与环境激活。
3. **查阅组件调用规范**：本项目实施严格的分层解耦设计，禁止重复编写底层驱动代码。在进行业务层开发前，请务必阅读 `common_components/USAGE_TUTORIAL.md`，以掌握公共组件库的架构接入与标准 API 调用方法。

## 📂 工程目录结构

```text
hardware/
├── docs/                   # 团队协作规范、架构设计方案、引脚分配表等核心技术文档
├── common_components/      # 【核心库】底层硬件抽象层(HAL)与基础服务组件(MQTT通信/网络配网等)
├── config_global/          # 全局配置宏 (网络IP地址、通用系统常量)
├── room_terminal/          # 客房端主业务工程 (门禁鉴权、强电继电器控制、语音交互采集)
├── front_desk_terminal/    # 前台管理端主业务工程 (刷卡发卡逻辑、房态展示矩阵)
└── floor_controller/       # 楼控端主业务工程 (走廊公共照明控制、环境温湿度与空气质量采集)
```

## 🛠️ 工程编译指南

1. **环境确认**：请确认系统已正确部署并激活 ESP-IDF 框架（基线推荐使用 v6.0 版本）。
2. **加载工作区**：请使用 VSCode 独立打开对应的业务终端目录（例如，以 `hardware/room_terminal` 作为 VSCode 的工作区根目录打开），以确保 CMake 构建系统正确识别项目边界。
3. **网络参数配置**：如需在局域网等非默认网络环境下进行联调测试，请修改全局配置文件 `common_components/config_global/include/global_config.h` 中的 `GLOBAL_MQTT_BROKER_URI` 宏，该修改将跨终端全局生效。
4. **执行构建**：通过 ESP-IDF 插件的 **Build** 工具执行编译。底层构建系统将自动加载当前目录下的 `sdkconfig.defaults` 以对齐硬件基线参数，并从官方组件注册表拉取外部缺失的依赖包。
