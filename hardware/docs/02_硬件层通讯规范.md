## 1. 概述

### 1.1 文档目的

本文档定义了硬件层（ESP32系列设备）与后端服务器之间的**通讯规范**，包括：

- ✅ 接口规范（REST API + MQTT）
- ✅ 通信协议（JSON格式）
- ✅ 发包结构（数据帧定义）
- ✅ 数据格式（编码、长度、类型）
- ✅ 消息类型（设备状态、传感器数据、控制指令）

### 1.2 适用设备

| 设备类型 | 主控芯片 | 通信方式 | 说明 |
|---------|---------|---------|------|
| **前台管理端** | ESP32-S3 N16R8 | WiFi + MQTT | 物理I/O，状态展示 |
| **楼控** | ESP32-S3 N16R8 | WiFi + MQTT | 环境监测 |
| **客房端** | ESP32-S3 N16R8 | WiFi + MQTT | 设备控制 |

### 1.3 通信拓扑

```
┌─────────────────────────────────────────────────────────┐
│                    🖥️ 后端服务器 (Node.js)                 │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌────────┐  │
│  │ REST API │  │  MQTT    │  │ WebSocket│  │  MySQL │  │
│  │  /api/v1 │  │  :1883   │  │  /ws     │  │  :3307 │  │
│  └──────────┘  └──────────┘  └──────────┘  └────────┘  │
└─────────────────────────────────────────────────────────┘
         │              │              │
         ▼              ▼              ▼
┌────────────────┐ ┌─────────────┐ ┌────────────────┐
│  前台管理端     │ │   楼控      │ │   客房端       │
│  (ESP32)       │ │  (ESP32)   │ │  (ESP32)      │
│  WiFi+MQTT     │ │  WiFi+MQTT │ │  WiFi+MQTT    │
└────────────────┘ └─────────────┘ └────────────────┘
```

## 2. 系统架构

### 2.1 三层架构

```
┌─────────────────────────────────────────────────────────┐
│                    📱 应用层（软件）                       │
│   前台端 / 管理端 / 客户端 (Vue3)                        │
├─────────────────────────────────────────────────────────┤
│                    🌐 网络层（通信）                       │
│   MQTT Broker (Mosquitto) + WebSocket + REST API       │
├─────────────────────────────────────────────────────────┤
│                    💾 存储层（数据）                       │
│   MySQL (设备/传感器/命令数据) + Redis (缓存)           │
├─────────────────────────────────────────────────────────┤
│                    🔌 硬件层（设备）                       │
│   前台管理端 / 楼控 / 客房端 (ESP32)                    │
└─────────────────────────────────────────────────────────┘
```

### 2.2 通信方式

| 通信方向 | 协议 | 端口 | 用途 | 说明 |
|---------|------|------|------|------|
| **设备 → 服务器** | MQTT | 1883 | 设备状态、传感器数据 | QoS 1 |
| **服务器 → 设备** | MQTT | 1883 | 控制指令下发 | QoS 1 |
| **服务器 ↔ 前台** | REST API | 9000 | 前台管理端数据交互 | HTTP/HTTPS |
| **服务器 ↔ 前端** | WebSocket | 9000 | 实时数据推送 | Socket.io |

## 3. 通信协议

### 3.1 MQTT协议

#### 3.1.1 连接参数

| 参数 | 值 | 说明 |
|------|-----|------|
| **协议** | MQTT 3.1.1 / 5.0 | |
| **端口** | 1883 (默认) / 8883 (TLS) | 开发环境默认1883，生产环境推荐8883 |
| **用户名** | `iot_user` | 可选 |
| **密码** | `IotHotel2026` | 可选 |
| **KeepAlive** | 60秒 | 心跳间隔 |
| **Client ID** | `front_desk_01` / `room_301` / `floor_03` | 唯一标识 |
| **重连策略** | 指数退避（1s/2s/4s/8s...上限60s） | 断线后自动重连并恢复订阅 |

#### 3.1.2 主题（Topic）结构

```
hotel/{category}/{action}/{device_type}/{device_id}
```

**示例**：
- `hotel/device/status/front_desk/001`
- `hotel/device/data/temperature/room_101`
- `hotel/device/command/room/301`

## 4. 接口规范

### 4.1 REST API接口

#### 4.1.1 设备注册

**接口**: `POST /api/v1/devices/register`  
**说明**: 设备首次上线时注册

**请求体**:
```json
{
  "device_id": "front_desk_01",
  "device_type": "front_desk",
  "device_name": "前台管理端-001",
  "firmware_version": "v1.0.0",
  "hardware_version": "v1.1",
  "mac_address": "A8:40:41:XX:XX:XX",
  "ip_address": "192.168.1.100",
  "location": "前台接待区",
  "capabilities": ["rfid", "rgb", "sos", "beep"]
}
```

**响应**:
```json
{
  "code": 200,
  "message": "设备注册成功",
  "data": {
    "device_id": "front_desk_01",
    "status": "online",
    "registered_at": "2026-04-07T00:00:00Z"
  }
}
```

#### 4.1.2 设备心跳

**接口**: `POST /api/v1/devices/heartbeat`  
**说明**: 定期上报设备在线状态

**请求体**:
```json
{
  "device_id": "front_desk_01",
  "status": "online",
  "battery_level": 100,
  "signal_strength": -45,
  "uptime": 86400,
  "memory_usage": 45
}
```

**响应**:
```json
{
  "code": 200,
  "message": "心跳上报成功",
  "data": null
}
```

#### 4.1.3 获取控制指令

**接口**: `GET /api/v1/devices/command`  
**说明**: 设备定期轮询待执行的指令

**请求参数**:
```
device_id=front_desk_01
```

**响应**:
```json
{
  "code": 200,
  "message": "获取指令成功",
  "data": {
    "commands": [
      {
        "command_id": 1,
        "command_type": "light_on",
        "command_value": "{\"room_id\":101}",
        "created_at": "2026-04-07T00:00:00Z",
        "status": "pending"
      }
    ]
  }
}
```

#### 4.1.4 上报传感器数据

**接口**: `POST /api/v1/devices/sensor`  
**说明**: 上报传感器采集的数据

**请求体**:
```json
{
  "device_id": "floor_03",
  "sensor_type": "temperature",
  "sensor_value": "25.5",
  "unit": "℃",
  "timestamp": "2026-04-07T00:00:00Z"
}
```

**响应**:
```json
{
  "code": 200,
  "message": "传感器数据上报成功",
  "data": null
}
```

### 4.2 MQTT接口

#### 4.2.1 设备状态主题

**主题**: `hotel/device/status/{device_type}/{device_id}`  
**方向**: 设备 → 服务器  
**QoS**: 1  
**说明**: 设备状态变更时上报

**消息体**:
```json
{
  "device_id": "front_desk_01",
  "device_type": "front_desk",
  "status": "online",
  "firmware_version": "v1.0.0",
  "timestamp": "2026-04-07T00:00:00Z"
}
```

#### 4.2.2 传感器数据主题

**主题**: `hotel/device/data/{sensor_type}/{device_id}`  
**方向**: 设备 → 服务器  
**QoS**: 1  
**说明**: 传感器数据上报

**支持的传感器类型**:
- `temperature` - 温度
- `humidity` - 湿度
- `light` - 光照强度
- `motion` - 人体感应
- `door` - 门磁状态
- `smoke` - 烟雾浓度
- `noise` - 噪音

**消息体**:
```json
{
  "device_id": "floor_03",
  "sensor_type": "temperature",
  "value": 25.5,
  "unit": "℃",
  "timestamp": "2026-04-07T00:00:00Z"
}
```

#### 4.2.3 控制指令主题

**主题**: `hotel/device/command/{device_type}/{device_id}`  
**方向**: 服务器 → 设备  
**QoS**: 1  
**说明**: 服务器下发控制指令

**消息体**:
```json
{
  "command_id": 1,
  "device_id": "front_desk_01",
  "command_type": "light_on",
  "command_value": "{\"room_id\":101}",
  "created_by": "system",
  "timestamp": "2026-04-07T00:00:00Z"
}
```

**客房语音通话控制补充**:
- `incoming_call`: 建立通话会话，设备进入通话中状态。
- `hangup_call`: 结束通话会话，设备退出通话中状态。
- 当 `command_type = incoming_call` 时，消息体应补充 `call_id` 与 `caller_id` 字段。

#### 4.2.4 指令执行结果主题

**主题**: `hotel/device/command/result`  
**方向**: 设备 → 服务器  
**QoS**: 1  
**说明**: 设备执行指令后的结果反馈

**消息体**:
```json
{
  "device_id": "front_desk_01",
  "command_id": 1,
  "command_type": "light_on",
  "status": "success",
  "result": "灯光已打开",
  "timestamp": "2026-04-07T00:00:00Z"
}
```

#### 4.2.5 安防事件主题

**主题**: `hotel/security/event`  
**方向**: 设备 → 服务器  
**QoS**: 1  
**说明**: 安防事件上报

**消息体**:
```json
{
  "device_id": "room_101",
  "event_type": "door_open",
  "event_data": {
    "room_id": 101,
    "door_type": "main"
  },
  "level": "info",
  "timestamp": "2026-04-07T00:00:00Z"
}
```

## 5. 数据格式

### 5.1 JSON编码

#### 5.1.1 基本规则

- **编码**: UTF-8
- **缩进**: 2空格（可选）
- **时间格式**: ISO 8601 (`YYYY-MM-DDTHH:mm:ss.sssZ`)

#### 5.1.2 数据类型

| 类型 | JavaScript | JSON | 说明 |
|------|-----------|------|------|
| **字符串** | `string` | `"value"` | UTF-8编码 |
| **数字** | `number` | `123` | 整数或浮点数 |
| **布尔** | `boolean` | `true/false` | |
| **数组** | `array` | `[1,2,3]` | |
| **对象** | `object` | `{"key":"value"}` | |
| **空值** | `null` | `null` | |

### 5.2 时间格式

```json
{
  "timestamp": "2026-04-07T00:00:00.000Z"
}
```

**说明**:
- 格式: `YYYY-MM-DDTHH:mm:ss.sssZ`
- 时区: UTC (Z表示零时区)
- 毫秒: `.sss` (可选)

### 5.3 错误码规范

| 错误码 | 含义 | 说明 |
|--------|------|------|
| `200` | 成功 | 操作成功 |
| `400` | 请求错误 | 参数缺失或格式错误 |
| `401` | 未授权 | JWT验证失败 |
| `404` | 资源不存在 | 设备或数据不存在 |
| `500` | 服务器错误 | 后端处理异常 |
| `1001` | 设备未注册 | 设备ID不存在 |
| `1002` | 指令执行失败 | 设备执行指令失败 |
| `1003` | 传感器数据异常 | 数据超出合理范围 |

## 7. 发包结构

```
┌─────────────────────────────────────────────────────────┐
│                    MQTT Packet                          │
├─────────────────────────────────────────────────────────┤
│  Fixed Header (2-5 bytes)                               │
│  ┌─────────────┬─────────────┬────────────────────────┐ │
│  │ Packet Type │ QoS Level   │ Retain Flag            │ │
│  │ (4 bits)    │ (2 bits)    │ (1 bit)                │ │
│  └─────────────┴─────────────┴────────────────────────┘ │
│                                                         │
│  Variable Header (variable)                             │
│  ┌────────────────────────────────────────────────────┐ │
│  │ Topic Name (UTF-8 string)                         │ │
│  └────────────────────────────────────────────────────┘ │
│                                                         │
│  Payload (JSON object)                                  │
│  ┌────────────────────────────────────────────────────┐ │
│  │ {"device_id":"001","status":"online",...}         │ │
│  └────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────┘
```

## 8. 通信流程

### 8.1 设备上线流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   设备       │     │  MQTT Broker│     │  后端服务器  │
└──────┬──────┘     └──────┬──────┘     └──────┬──────┘
       │                   │                   │
       │ 1. 连接MQTT       │                   │
       │──────────────────>│                   │
       │                   │                   │
       │ 2. 发布上线消息   │                   │
       │hotel/device/status│                   │
       │──────────────────>│                   │
       │                   │                   │
       │                   │ 3. 推送WebSocket │
       │                   │◄──────────────────│
       │                   │                   │
       │ 4. REST API注册   │                   │
       │◄──────────────────│                   │
       │  /api/v1/devices/  │                   │
       │       register     │                   │
       │                   │                   │
       │ 5. 上报心跳       │                   │
       │hotel/device/data/ │                   │
       │──────────────────>│                   │
       │                   │                   │
```

### 8.2 指令下发流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   前台电脑   │     │  后端服务器  │     │   设备       │
└──────┬──────┘     └──────┬──────┘     └──────┬──────┘
       │                   │                   │
       │ 1. 提交控制请求   │                   │
       │POST /api/v1/...   │                   │
       │──────────────────>│                   │
       │                   │                   │
       │                   │ 2. 保存指令到DB │
       │                   │◄──────────────────│
       │                   │                   │
       │                   │ 3. MQTT下发指令 │
       │                   │hotel/device/... │
       │                   │──────────────────>│
       │                   │                   │
       │ 4. 接收指令结果   │                   │
       │◄──────────────────│                   │
       │  WebSocket推送    │                   │
       │                   │                   │
       │ 5. 执行指令       │                   │
       │                   │◄──────────────────│
       │                   │                   │
       │ 6. 上报执行结果   │                   │
       │hotel/device/...   │                   │
       │──────────────────>│                   │
       │                   │                   │
```

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│   设备       │     │  MQTT Broker│     │  后端服务器  │
└──────┬──────┘     └──────┬──────┘     └──────┬──────┘
       │                   │                   │
       │ 1. 采集传感器数据 │                   │
       │  (温度/湿度等)    │                   │
       │                   │                   │
       │ 2. MQTT发布消息   │                   │
       │hotel/device/data/ │                   │
       │──────────────────>│                   │
       │                   │                   │
       │                   │ 3. 保存到数据库 │
       │                   │◄──────────────────│
       │                   │ (sensor_data表)  │
       │                   │                   │
```

## 10. 开发指南

### 10.1 ESP32开发环境

#### 10.1.1 ESP-IDF配置

1. **安装ESP-IDF**:
   - 下载安装 [ESP-IDF v6.0](https://github.com/espressif/esp-idf)
   - 配置环境变量

2. **安装VSCode插件**:
   - 搜索 `Espressif IDF` 并安装

3. **基本代码框架**:

```cpp
#include <WiFi.h>
#include <PubSubClient.h>
#include <ArduinoJson.h>
#include "global_config.h"  // 引入全局配置

// 配置参数
const char* ssid = "WiFi_SSID";
const char* password = "WiFi_PASSWORD";
const char* mqtt_broker = GLOBAL_MQTT_BROKER_URI;  // 从global_config.h读取MQTT Broker地址
const char* device_id = "front_desk_01";

// MQTT客户端
WiFiClient espClient;
PubSubClient client(espClient);

// 回调函数 - 处理接收到的消息
void callback(char* topic, byte* payload, unsigned int length) {
  Serial.print("收到消息 [");
  Serial.print(topic);
  Serial.print("]: ");
  
  String message;
  for (unsigned int i = 0; i < length; i++) {
    message += (char)payload[i];
  }
  
  Serial.println(message);
  handleCommand(message);
}

// 连接MQTT
void connectMQTT() {
  while (!client.connected()) {
    Serial.print("连接MQTT...");
    if (client.connect(device_id)) {
      Serial.println("连接成功");
      client.subscribe("hotel/device/command/#");
    } else {
      Serial.print("失败, rc=");
      Serial.print(client.state());
      delay(5000);
    }
  }
}

// 发布设备状态
void publishStatus(String status) {
  String topic = "hotel/device/status/front_desk/" + device_id;
  String payload = "{\"device_id\":\"" + device_id + "\",\"status\":\"" + status + "\",\"timestamp\":\"" + getCurrentTime() + "\"}";
  client.publish(topic.c_str(), payload.c_str());
}

// 发布传感器数据
void publishSensorData(String sensorType, float value) {
  String topic = "hotel/device/data/" + sensorType + "/" + device_id;
  String payload = "{\"device_id\":\"" + device_id + "\",\"sensor_type\":\"" + sensorType + "\",\"value\":" + String(value) + ",\"timestamp\":\"" + getCurrentTime() + "\"}";
  client.publish(topic.c_str(), payload.c_str());
}

// 处理指令
void handleCommand(String jsonStr) {
  StaticJsonDocument<256> doc;
  DeserializationError error = deserializeJson(doc, jsonStr);
  
  if (error) {
    Serial.println("JSON解析失败");
    return;
  }
  
  int commandId = doc["command_id"];
  String commandType = doc["command_type"];
  
  bool result = executeCommand(commandType);
  
  String resultTopic = "hotel/device/command/result";
  String resultPayload = "{\"device_id\":\"" + device_id + "\",\"command_id\":" + String(commandId) + ",\"command_type\":\"" + commandType + "\",\"status\":\"" + (result ? "success" : "failed") + "\",\"timestamp\":\"" + getCurrentTime() + "\"}";
  client.publish(resultTopic.c_str(), resultPayload.c_str());
}

void setup() {
  Serial.begin(115200);
  
  WiFi.begin(ssid, password);
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nWiFi连接成功");
  
  client.setServer(mqtt_broker, mqtt_port);
  client.setCallback(callback);
  connectMQTT();
  
  publishStatus("online");
}

void loop() {
  if (!client.connected()) {
    connectMQTT();
  }
  client.loop();
  
  float temperature = readTemperature();
  float humidity = readHumidity();
  
  publishSensorData("temperature", temperature);
  publishSensorData("humidity", humidity);
  
  delay(5000);
}
```

### 11.1 配置MQTT Broker地址

**配置位置**: [global_config.h](file:///d:/IoT_Smart_Hotel_System/hardware/common_components/config_global/include/global_config.h#L16)

```c
// 后台 MQTT 服务器地址配置
// 开发环境: mqtt://192.168.1.100:1883
// 云服务器: mqtt://your-domain.com:1883 或 mqtt://your-server-ip:1883
```

- **云服务器**: 将 `your-domain.com` 替换为云服务器域名或IP，`1883` 为默认端口
- **生产环境**: 使用 `mqtts://` 协议启用TLS加密，端口 `8883`
- **协议**: MQTT 3.1.1 / 5.0

**部署示例**:

| **生产环境** | `mqtts://mqtt.example.com:8883` | 云服务器TLS加密 |
