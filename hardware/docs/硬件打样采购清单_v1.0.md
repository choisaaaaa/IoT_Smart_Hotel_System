# 智慧酒店物联网控制系统 - 硬件打样采购清单 (硬件组提案版 v1.0)


## 1. 核心主控与共用模块 (全终端标配)

| 序号 | 物料名称 | 规格参数/选型要求 | 预估数量 (按1套系统计) | 用途说明 | 硬件组长特别提醒 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1.1 | **ESP32 开发板** | `ESP32-WROOM-32` (Type-C接口，CP2102/CH340) | 3 片 + 1备用 | 前台、楼控、客房三大终端的主控核心 | 必须买带排针的开发板，方便插拔打样 |
| 1.2 | **0.96寸 OLED 屏** | **I2C接口** (4针: VCC, GND, SCL, SDA) | 2 块 | 前台端状态显示、客房端呼叫提示 | **绝对不能买 SPI 接口（6/7针）的**，引脚不够 |
| 1.3 | **RFID 读卡模块** | `RC522` **(I2C接口版)** | 2 块 | 前台发卡、客房门禁 | **极其重要：市面默认是SPI版，必须专门搜索买"I2C接口版"**，与OLED共用总线省引脚 |
| 1.4 | **USB 数据线** | Type-C 数据线 | 3 根 | 烧录代码与供电 ||
| 2.1 | **全彩 RGB 灯带/板** | `WS2812B` (8灯珠或以上) | 1 条/块 | 房态可视化展示墙 |
| 2.2 | **有源蜂鸣器模块** | 5V / 3.3V 均可（高/低电平触发选其一即可） | 1 个 | 刷卡成功/报警提示音 |
| 2.3 | **独立按键模块** | 机械轻触按键模块（带键帽） | 2-3 个 | 入住/退房/SOS报警触发 |
| 3.1 | **温湿度传感器** | `DHT11` 模块（带上拉电阻版） | 1 个 | 走廊环境温湿度采集 |
| 3.2 | **空气质量/烟雾传感器** | `MQ-2` 模块（ADC模拟输出） | 1 个 | 走廊烟雾/可燃气体报警检测 (更适合烟雾检测) |
| 3.3 | **光敏电阻模块** | 带 LM393 比较器及 AO 模拟输出 | 1 个 | 走廊光照采集，联动公共照明 |
| 3.4 | **继电器模块** | 2路 5V 继电器模块（带光耦隔离） | 1 块 | 控制走廊灯光、排风机 |
| 3.5 | **全彩 RGB 灯珠** | `WS2812B` (单颗或小板) | 1 个 | 楼控设备状态指示灯 |
| 4.1 | **继电器模块** | 4路 5V 继电器模块（带光耦隔离） | 1 块 | 控制客房灯光、插座、窗帘、电磁门锁 | 必须带光耦隔离，防止继电器吸合反向击穿ESP32 |
| 4.2 | **红外发射模块** | `红外发射管` (38KHz) | 1 个 | 模拟控制客房空调、电视 | |
| 4.3 | **红外接收模块** | `VS1838B` 接收头模块 | 1 个 | 学习遥控器红外码 | |
| 4.4 | **数字麦克风模块** | `INMP441` (I2S接口，全向) | 1 个 | 呼叫前台时采集语音 | 保证数字抗干扰，低算力高可懂度 |
| 4.5 | **音频功放模块** | `PAM8403` (微型 3W D类功放) | 1 块 | 放大 ESP32 DAC 输出的模拟音频 | 需在输入端自行加焊 RC 低通滤波电容电阻 |
| 4.6 | **扬声器 (喇叭)** | 3W 4欧 或 8欧（带腔体更佳） | 1 个 | 前台广播与消防报警发声 | |
| 4.7 | **有源蜂鸣器模块** | 同前台端 | 1 个 | 刷卡反馈音 | |
| 4.8 | **全彩 RGB 灯板** | `WS2812B` (4-8灯珠) | 1 块 | 客房内状态/报警光效演示 | |
| 4.9 | **独立按键模块** | 同前台端 | 3-4 个 | 呼叫前台键、SOS键、本地控制键 | **接 GPIO34/35 的按键必须在硬件电路上加拉电阻** |
| 4.10 | **人体存在/移动传感器** | `HLK-LD2410` (毫米波) 或 `HC-SR501` (PIR) | 1 个 | 客房人体存在检测，推荐雷达以支持静止存在 | |
| 4.11 | **门磁传感器 (干簧管)** | 标准有线干簧管门磁 | 1 个 | 监测客房门开关状态 (0/1) | |
| 5.1 | **面包板** | 830孔或 400孔（中/大号） | 3-4 块 | 无损搭建原型测试电路 |
| 5.2 | **杜邦线** | 公对母、公对公、母对母 (20cm) | 各 1-2 把 | 模块连线 |
| 5.3 | **电阻包** | 常用阻值 (4.7K, 10K 等) | 1 盒 | 上拉/下拉电阻、音频滤波用 |
| 5.4 | **电容包** | 常用容值 (104陶瓷, 10uF电解等) | 1 盒 | 音频低通滤波、电源稳压用 |
| 5.5 | **5V 电源适配器** | 5V / 2A (带DC接头或接线端子) | 3 个 | 独立给继电器和ESP32供电 |
