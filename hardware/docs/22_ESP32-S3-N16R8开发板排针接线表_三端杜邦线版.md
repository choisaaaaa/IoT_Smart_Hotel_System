# ESP32-S3 N16R8 开发板排针接线表（三端杜邦线版）

> 适用对象：ESP32-S3 N16R8 双 Type-C 开发板（焊接排针）。  
> 适用阶段：原型验证（杜邦线连接外设）。  
> 参考文档：`03_硬件制图与实施交付手册_原型验证分板版_v1.0.md`。  
> 配套操作教程：`24_硬件杜邦线傻瓜接线教程_v1.0.md`（文内版本 **v1.1**；按步骤接线、上电顺序与排障；**5V 大电流默认电源模块**）。

---

## 1. 适配范围与引脚约束

### 1.1 适配说明
- 本文档以“开发板实际排针丝印 GPIO”为准，不采用芯片全集引脚。
- 三端（前台、楼控、客房）均使用独立主控板，允许相同 GPIO 编号在不同终端重复使用。

### 1.2 禁用与慎用引脚
- 禁止接外设负载：`GPIO35`、`GPIO36`、`GPIO37`、`GPIO45`、`GPIO46`、`GPIO0`、`GPIO3`。
- 慎用：`GPIO19`、`GPIO20`（与 USB 调试链路相关，建议仅用于低频输入）。

### 1.3 电源与电平要求
- 所有外设与主控必须共地（GND 共地）。
- `MQ-2 AO` 若为 5V 模拟输出，必须分压后接入 ESP32 ADC。
- 继电器、舵机、功放、WS2812B 等 5V 负载建议使用独立 5V 电源。

### 1.4 标注含义（对照《03》冻结引脚与基线外设）

| 标注 | 含义 |
| :--- | :--- |
| **原有** | 外设属于项目基线（`01_硬件架构与设计基线_v1.0.md` / `03_...`），且 **GPIO 与《03》冻结表一致**。 |
| **适配变更** | 外设仍为基线既有，因 **开发板排针无法引出原 GPIO** 或避让禁用脚，**仅 GPIO 重映射**；与当前仓库 `global_config.h` 默认值可能不一致，须改宏。 |
| **文档补充** | 基线已有外设，本文档补充 **接线细节**（如 `RST` 悬空），不引入新器件。 |
| **可选** | 基线或联调文档中已出现、可按项目裁剪的接线项。 |

> 对照基准：`03_硬件制图与实施交付手册_原型验证分板版_v1.0.md` 各端「引脚编号 / 功能分配」表。

## 2. 前台端接线表（Front Desk Terminal）

### 2.1 RC522 读卡模块（SPI）

> **供电丝印**：多数 RC522 小板标为 **`3.3V`**（或 **`3.3V`/`VCC` 同义**），接开发板 **`3V3`**；若模块丝印为 **`5V`**，须使用 **3.3V 电平兼容** 的 RC522 子板或经电平转换后再接 SPI，禁止将 5V 信号直连 ESP32 GPIO。  
> **IRQ**：中断输出；本项目 SPI 轮询/驱动未用时接 **`NC`** 即可。

| 模块名称 | 模块引脚 | 开发板引脚 | 标注 |
| :--- | :--- | :--- | :--- |
| RC522 读卡器 | `SDA/SS` | `GPIO10` | 原有 |
| RC522 读卡器 | `SCK` | `GPIO12` | 原有 |
| RC522 读卡器 | `MOSI` | `GPIO11` | 原有 |
| RC522 读卡器 | `MISO` | `GPIO13` | 原有 |
| RC522 读卡器 | `3.3V` 或 `VCC` | `3V3` | 原有（丝印以模块为准） |
| RC522 读卡器 | `GND` | `GND` | 原有 |
| RC522 读卡器 | `IRQ` | `NC`（未使用） | 文档补充 |
| RC522 读卡器 | `RST` | `NC`（未使用） | 文档补充 |

## 3. 楼控端接线表（Floor Controller）

> **变更说明**：楼控 **不再使用电位器**（原 `ADC_IN_4` 方案已废弃）；`GPIO7`（《03》中原电位器脚）在楼控板上 **NC**。

### 3.1 传感器与继电器

| 功能 | 模块名称 | 模块引脚 | 开发板引脚 | 说明 | 标注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| MQ-2 模拟量 | MQ-2 烟雾传感器模块 | `AO` | `GPIO1` | 5V AO 必须分压 | 适配变更（《03》为 `GPIO4`） |
| 光敏模拟量 | 光敏电阻模块 | `AO` | `GPIO2` | ADC 输入 | 适配变更（《03》为 `GPIO5`） |
| 温湿度（替代 NTC） | DHT11 温湿度模块 | `DATA` | `GPIO15` | 单总线数字协议；建议供电 `3V3` | 适配替换（替代原 NTC 仅温度方案） |
| 继电器控制 | 继电器模块（通道 1） | `IN1` | `GPIO17` | 低电平有效 | 原有 |
| 楼道报警按键 | 轻触按键模块 | `KEY` | `GPIO18` | 低电平有效 | 适配变更（《03》为 `GPIO19`） |
| NTC 温度（不采用） | NTC 热敏电阻模块 | — | `NC` | 已由 **DHT11** 同时提供温度+湿度 | 不装 |

> **DHT11 接线补充**：`VCC/VDD` 接 `3V3`（或按模块允许接 `5V`）；`GND` 接 `GND`；`DATA` 接 `GPIO15`。若模块无板上拉，请在 `DATA` 与 `3V3` 之间加 **4.7kΩ～10kΩ** 上拉电阻。

### 3.2 电源连接

| 模块 | 供电 |
| :--- | :--- |
| MQ-2 | `5V + GND` |
| 光敏模块 | 按模块规格接 `3V3` 或 `5V` |
| DHT11 | 推荐 `3V3 + GND`（与 `DATA` 电平一致） |
| 继电器 | `5V + GND` |

> **螺丝端子控制口（无杜邦排针的 4 路继电器）**：控制侧常见为 6 位蓝色端子，丝印多为 **`IN1`～`IN4`、`DC+`、`DC-`**（上下顺序以你板子为准）。**无排针时用剥线线芯或「一端杜邦母头、一端裸线」** 插入端子孔再拧紧螺丝即可。电气关系不变（与 **`24` v1.1** 一致，推荐减轻 USB 负担）：**`DC+` → 独立电源模块 `+5V`，`DC-` → 模块 `GND`（与 ESP32 开发板 `GND` 共地）**；**`IN1`～`IN4` → 上表四路 `GPIO`**。若临时调试也可接开发板 **`5V IN`/`5V` 丝印脚**，注意 USB 供电电流上限。板上 **Low / Com / High** 跳线请选 **低电平触发**，与仓库默认 **`hal_actuators` 低有效** 一致；若误设为高电平触发，吸合逻辑会与软件相反。

### 4.4 客房端供电要求
- 继电器、舵机、功放等高负载模块使用 **`5V` 供电并与主控共地**；**推荐由独立电源模块输出 `+5V`/`GND` 供电**（见 **`24` §0.1**），开发板 USB 仅作调试与小电流负载。
- 建议在 **电源模块至继电器的 `5V` 轨** 并联 `1000uF` 电解电容以抑制瞬态压降。

## 6. 上电联调顺序

1. 仅连接电源与地线，确认主控稳定启动。  
2. 连接输入类外设（按键、传感器），确认无异常复位。  
3. 连接高负载外设（继电器、舵机、灯带、功放），逐项动作测试。  
4. 若出现重启，优先检查 5V 电源能力、共地状态、分压电路与禁用引脚占用。
