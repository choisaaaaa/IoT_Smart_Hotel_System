# 硬件杜邦线傻瓜接线教程（ESP32-S3 N16R8 开发板）v1.1

> **文档定位**：面向原型阶段「第一次接线」，**三端分开写**，每端按顺序做完即可。  
> **GPIO 与模块引脚以** `22_ESP32-S3-N16R8开发板排针接线表_三端杜邦线版.md` **为唯一依据**；本教程只补充「先接谁、怎么并线、别踩坑」。  
> **主控板**：双 Type-C、两排杜邦排针、丝印 GPIO 与 `22` 一致的那款 S3-N16R8 开发板。  
> **v1.1**：凡文档中需要 **5V** 的负载（MQ-2、继电器线圈、功放、灯带、可选 5V 蜂鸣器等），**默认改由独立电源模块供电**，**不与笔记本 USB 抢电流**；开发板仍可用 USB 调试供电，**必须与电源模块 `GND` 共地**。

---

## 0. 三端共用的准备清单

- 主控板 **3 块**（前台 / 楼控 / 客房各 1 块；已焊线板子不要混用）  
- **5V 电源模块至少 1 块**（降压/稳压到 **5.0V±0.2V**，电流能力按负载留余量；上电前用万用表确认输出电压）  
- 杜邦线若干（母对母 / 公对母按模块接口选）  
- 面包板或洞洞板（推荐，便于 **`3V3`（开发板）**、**`+5V`（电源模块输出）**、**公共 `GND`** 分区并线）  
- **楼控专用**：MQ-2 分压电阻 `1kΩ`、`2kΩ` 各 1 只  
- 万用表（上电前测 **电源模块输出 5V 对 GND 是否短路**、分压中点是否开路焊错）

### 0.1 电源模块怎么用（本教程全文默认）

| 接点 | 接到哪里 |
| :--- | :--- |
| 电源模块 **`+5V` / `VOUT` / `+`**（输出正） | **`MQ-2` 的 `VCC`**、**继电器 `DC+`**、**功放 `VCC`（若 5V）**、**WS2812 `5V`（若用）**、蜂鸣器若丝印要求 **`5V` 的 `VCC`** 等 |
| 电源模块 **`GND` / `-`**（输出负） | 上述各模块 **`GND` / `DC-`**，且 **必须与 ESP32 开发板任意 `GND` 连在一起（共地）** |
| ESP32 开发板 | **仍用 USB 供电即可**（刷程序、调试）；**不要**指望 USB 给四路继电器 / MQ-2 / 大功放拖满电流 |

**铁律**：外设 **`GND`、`DC-`** 与板子 **`GND`** 必须同一地网；**信号线 `IN` / `INx` / `DATA` 仍只接 GPIO**，不要把模块 **5V** 误接到 GPIO。电解电容（如继电器轨 **1000µF**）焊在 **电源模块 5V 与 GND 之间、靠近继电器 `DC+`/`DC-`** 更见效。

---

## 1. 三端共用的六条铁规矩

1. **所有模块 GND 与主控 GND 连在一起**（共地）。  
2. **任何信号进 ESP32 GPIO 不得超过 3.3V**；MQ-2 在 `5V` 供电时 `AO` 常见 0～5V，**必须分压**后进 ADC。  
3. **MQ-2 用 `5V` 供电**（加热丝需要），**正极接电源模块 `+5V`，负极接模块 `GND` 并与板子共地**（不要从笔记本 USB 取大电流）。  
4. **继电器 / 灯带 / 舵机 / 功放**等大电流负载，**一律由电源模块 `+5V` 供电**，并与主控 **共地**。
5. **禁止接外设负载的脚**：`GPIO0`、`GPIO3`、`GPIO35`、`GPIO36`、`GPIO37`、`GPIO45`、`GPIO46`。  
6. **`GPIO20` 慎用**（与 USB 调试相关）；客房「场景键」若接此脚，烧录异常时可先断开排查。

# 第一部分：前台端（Front Desk Terminal）

## 1.1 本端要接哪些东西（最少可跑通）

| 顺序 | 模块 | 作用 |
| :---: | :--- | :--- |
| ① | RC522 读卡器 | 发卡 / 验卡 |
| ② | 有源蜂鸣器 | 提示音 |
| ③ | 按键 ×2 | 消音 / 广播（逻辑名以软件为准） |
| ④（可选） | WS2812B 灯带 | 房态灯墙 |

详表见 **`22` 文档 §2**。

## 1.2 傻瓜步骤（按编号做）

**步骤 ①：RC522（只有 1 个模块）**

- `SDA/SS → GPIO10`，`SCK → GPIO12`，`MOSI → GPIO11`，`MISO → GPIO13`  
- `3.3V` 或 `VCC → 3V3`，`GND → GND`  
- `IRQ`、`RST`：**不接**

> 模块若只印 `3.3V` 没有 `VCC`，**`3.3V` 就是供电正极**，接开发板 `3V3`。

**步骤 ②：蜂鸣器**

- `IN → GPIO38`  
- 模块 `VCC`：丝印 **`3V3` / `3.3V`** 则接开发板 **`3V3`**；丝印要求 **`5V`** 则接 **电源模块 `+5V`**（**`GND` 与开发板 `GND` 共地**）

**步骤 ③：两个按键**

- **裸按键 4 脚**：对角一组接 `GPIO`，另一组接 `GND`（不要同一侧两脚当 GPIO+GND）。  
  - 键1：`GPIO5` + `GND`  
  - 键2：`GPIO6` + `GND`  
- **三针模块键**（`VCC/GND/OUT`）：`VCC→3V3`，`GND→GND`，`OUT→GPIO5` 与 `OUT→GPIO6`  

**步骤 ④（可选）：灯带**

- `DIN → GPIO21`，**`5V`（灯带）→ 电源模块 `+5V`**，**`GND` → 电源模块 `GND` 并与开发板 `GND` 共地**（灯珠多必须用模块供电，减轻 USB 压力）

## 1.3 前台端上电检查

1. 只插 USB，确认主控能启动。  
2. 只接 RC522，再上电。  
3. 再蜂鸣器 → 再按键 → 最后灯带。  
4. 一上电就复位：查 **`3V3` 是否虚接**、**电源模块 `+5V`/`GND` 是否接牢**、**地与开发板是否共地**、灯带/继电器是否仍误从 USB 取大电流。

# 第二部分：楼控端（Floor Controller）

## 2.1 本端要接哪些东西

| 顺序 | 模块 | 作用 |
| :---: | :--- | :--- |
| ① | MQ-2 | 烟雾模拟量（只接 `AO` 即可） |
| ② | 光敏模块 | 光照 ADC |
| ③ | DHT11 / ASAIR 小蓝块 | 温湿度（**替代 NTC**，不再接 NTC） |
| ④ | 继电器 ×1 | 走廊灯等 |
| ⑤ | 楼道报警按键 | 低电平有效 |

详表见 **`22` 文档 §3**。

## 2.2 傻瓜步骤（按编号做）

**步骤 ①：MQ-2（只接 AO，推荐）**

- 模块：`VCC` → **电源模块输出 +5V**；`GND` → **电源模块 GND** 并与开发板 **`GND` 共地**；`AO` 出线；**`DO` 不接**
- **分压**（焊在靠近主控一侧）：

```
模块 AO ----[1kΩ]----●---- GPIO1
                     |
                    [2kΩ]
                     |
                    GND（= MQ 的 GND = 主控 GND）
```

**步骤 ②：光敏**

- 推荐：`VDD/VCC → 3V3`，`GND → GND`，`AO → GPIO2`；`DO` 可不接  
- 若光敏必须用 `5V` 供电： **`VCC` → 电源模块 +5V**，**`GND` → 电源模块 GND 并与开发板共地**；若 `AO` 可能超过 3.3V，则 `AO` 同样做 **1k+2k 分压** 再进 `GPIO2`

**步骤 ③：DHT11 / ASAIR（替代 NTC）**

- 常见丝印：`I/O` — `NC` — `GND` — `3V3`（以实物为准）  
- `3V3 → 3V3`，`GND → GND`，**`I/O`（= 数据线）→ `GPIO15`**，`NC` 不接  
- **不要再接 NTC**；原 NTC 用的 `GPIO7` **悬空**  
- 读数总失败时，再在 **`I/O` 与 `3V3` 之间加 4.7kΩ～10kΩ** 上拉

**步骤 ④：继电器**

- `IN1 → GPIO17`；继电器 **`DC+` → 电源模块 +5V**，**`DC-` → 电源模块 GND** 并与开发板 **`GND` 共地**

**步骤 ⑤：楼道报警键**

- 一脚 `GPIO18`，一脚 `GND`

## 2.3 楼控端上电检查

1. 万用表：**电源模块输出 +5V 与 GND 不短路**；模块已调 **5V** 再接负载。  
2. 确认 **MQ-2 分压中点** 接到 `GPIO1`，不是把 `AO` 直连 `GPIO1`。  
3. 先只接 MQ + 光敏 + DHT，上电稳定后，再接继电器。

# 第三部分：客房端（Room Terminal）

## 3.1 本端要接哪些东西（最多，分四批）

| 批次 | 内容 |
| :--- | :--- |
| 第一批 | RC522、OLED、毫米波（S3KM1110 / OT2 方案） |
| 第二批 | 四路继电器 |
| 第三批 | 红外发射/接收、EC11、PTT / SOS / 场景键 |
| 第四批 | I2S 麦克风 + 功放 |

详表见 **`22` 文档 §4**。

## 3.2 傻瓜步骤（按批次做，每批上电测一次）

**第一批：通信骨架**

- RC522（与前台 **§1.2 步骤①**、`22` **§4.2** 相同引脚）：**`SDA/SS → GPIO10`**，**`MOSI → GPIO11`**，**`MISO → GPIO13`**，**`SCK → GPIO12`**；**`3.3V`/`VCC → 3V3`**，**`GND → GND`**；**`IRQ`、`RST` 不接**；`W25Q64` 若不焊则其 **`CS`（`GPIO9`）不接**  
- OLED：`SDA→GPIO21`，`SCL→GPIO8`，`3V3`，`GND`  
- 毫米波雷达 S3KM1110（与 `22` §4.1 一致）：**模组 `OT2` → 开发板 `GPIO16`**；**`3V3`、`GND`**；**`OT1`、`RX` 默认不接**（本仓库按 `driver_rd03_simple` 读高低电平；若你手头的说明书要求 UART，再改用 `driver_rd03_uart` 并按手册改脚）

**第二批：继电器**

- `IN1→GPIO17`，`IN2→GPIO18`，`IN3→GPIO5`，`IN4→GPIO6`  
- 继电器线圈供电：**`DC+` → 电源模块 +5V**，**`DC-` → 电源模块 GND**（**必须与开发板 GND 共地**）；**不要**接开发板丝印 `5V IN` / USB 取大电流
- **没有排针、只有螺丝端子时**：把杜邦线**在继电器这一头剪掉胶壳**，剥出约 **5～7 mm** 铜线，插入对应端子孔，**螺丝拧紧**（轻拉不掉线为准）；或用细导线 + 压接针形/管型端子更稳。负载侧 **`NO` / `COM` / `NC`** 往往也是螺丝端子，接法相同；强电改灯/锁须持证电工操作，课堂演示请只用安全低压负载。
- 板子上的 **低/高电平触发** 跳线选 **低电平触发**，与仓库默认逻辑一致（选错则软件「开灯」时继电器可能反着动）。

**第三批：红外 + EC11 + 按键**

- **红外接收**（你这种 **1838 三针小板**，丝印常为 **`S` / 中间电源 / `−`**）：**`S` → `GPIO48`（`IR_RX`）**；**中间脚 → `3V3`**（电流很小，优先用开发板 `3V3`；若模块说明书要求 **5V** 再改接 **电源模块 +5V** 并 **共地**）；**`−` → `GND`**  
- **红外发射**（**独立发射管**，不是带驱动的小板）：**禁止**把发射管直接接 **5V** 或 **无电阻的 GPIO**。接法：**`GPIO47` → 串联限流电阻约 `100Ω～330Ω`（1/4W）→ 发射管阳极（通常腿长）→ 发射管阴极（通常腿短）→ `GND`**。软件里 `driver_ir_tx` 在 `GPIO47` 上输出载波，靠电阻限流即可课堂演示。  
- 若开发板 **板载 RGB 占用 `GPIO48`**，与 `IR_RX` 冲突时二选一或改脚，见 **`22` / `23`** 说明。  
- EC11：`CLK→GPIO2`，`DT/B→GPIO38`，`SW→GPIO4`（按你这块开发板无 `GPIO43/44` 适配）  
- PTT：`GPIO1` 与 `GND`  
- SOS：`GPIO7` 与 `GND`  
- 场景：`GPIO20` 与 `GND`（慎用，见 §1 铁规矩第 6 条）

**第四批：音频 I2S**

- `BCLK→GPIO42`，`WS→GPIO41`，`麦克风采样→GPIO40`，`功放数据→GPIO39`  
- 功放模块（若丝印 **5V**）：**`VCC` → 电源模块 +5V**，**`GND` → 电源模块 GND**（**并与开发板 GND 共地**）

## 3.3 客房端上电检查

1. 先不接继电器与功放，只跑第一批，确认能启动。  
2. 每加一批，重启观察是否掉电复位。  
3. 一吸合继电器就复位：在 **电源模块 +5V 与 GND 之间、靠近继电器 `DC+`/`DC-`** 加 **1000µF** 电解（见 `22` §4.4），并检查 **模块与开发板共地**、模块输出电流是否够用。

# 附录 A：3V3 / 电源模块 +5V 不够用时怎么并线

- **`3V3`**：可把多根杜邦线 **焊成三叉**，把 **`3V3` 或 `GND`** 分给多个小电流模块（RC522、OLED、雷达等）。  
- **`+5V`（电源模块输出）**：同样可用 **面包板电源轨** 或 **焊三叉**，分给 **MQ-2 `VCC`、继电器 `DC+`、功放 `VCC`、灯带 `5V`** 等；**所有用模块供电的模块 `GND`/`DC-` 必须与模块 GND 相连，再与开发板 GND 共地**。  
- **只对电源线并线**；SPI/I2C 等信号线不要随意分叉。  
- 焊点绝缘 + 应力固定。

---

# 附录 B：上电与排障（三端通用）

1. 只插 USB，确认主控能启动。  
2. 先接传感器类，再接执行器类。  
3. 一上电就复位：查 **电源模块输出电流是否够、共地、MQ 分压、是否把 +5V 误接进 GPIO**。

# 附录 C：接线完成后与代码的关系

若完全按 **`22`** 的开发板适配脚位接线，需同步修改 `hardware/common_components/config/config_global/include/global_config.h`（见 **`22` §5**），或单独维护 `global_config_devboard.h`。  

楼控 **DHT11 替代 NTC** 时：温湿度走 **`GPIO15` 单总线**（如 `driver_dht11_init(15)`），**勿再按 NTC 对 `GPIO7` 做 ADC 解读**。
