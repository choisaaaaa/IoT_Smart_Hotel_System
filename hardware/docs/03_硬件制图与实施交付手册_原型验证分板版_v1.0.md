## 1. 统一 ESP32-S3 引脚分配表 (按终端拆分)

> **致制图与硬件工程师的特别说明**：
> 本项目物理上分为**三块独立的 PCB 板**（客房板、前台板、楼控板），每块板子各有一颗 `ESP32-S3 N16R8`。
> 为了软件底层驱动库的统一与防冲突，我们采用了“全局不重叠”的引脚分配策略。
> **画图操作指南**：请分别建立 3 个 PCB 工程，对照下方各自的表格连线。**如果某个引脚不在当前板子的表格中，请在当前板子的 ESP32 上将其悬空（NC）处理。**

## 3. 被动件（电阻/电容）精确落点要求

画图与接线时，请严格按此表放置阻容元件。

| 网络/引脚 | 元件规格 | 放置位置要求 | 作用说明 |
| :--- | :--- | :--- | :--- |
| **ESP32-S3 3.3V 输入** | 104 陶瓷电容 | 极靠近 ESP32 的 3.3V 与 GND 引脚 | 高频去耦，防芯片死机 |
| **RC522 3.3V 输入** | 104 陶瓷电容 | 靠近 RC522 模块电源脚 | 高频去耦 |
| **RD-03 3.3V 输入** | 104 陶瓷电容 | 靠近雷达模块电源脚 | 高频去耦 |
| **I2C_SDA (GPIO21)** | 10K 直插电阻 | 并联在 SDA 与 3.3V 之间 | I2C 总线上拉（若模块自带可省，建议预留） |
| **I2C_SCL (GPIO8)** | 10K 直插电阻 | 并联在 SCL 与 3.3V 之间 | I2C 总线上拉 |
| **独立按键/轻触开关** | 104 陶瓷电容 | 并联在按键引脚与 GND 之间 | 硬件去抖动 |
| **独立按键/轻触开关** | 10K 直插电阻 | 并联在按键引脚与 3.3V 之间 | 外部上拉（增强抗干扰） |
| **DHT11 数据脚** | 4.7K 或 10K 电阻 | 并联在数据脚与 3.3V 之间 | 单总线上拉 |
| **总电源入口 (5V)** | 1000uF 电解电容 | 靠近 5V 适配器接入点 | 低频稳压，防瞬间大电流拉低总线 |
| **SG90 舵机 5V 输入** | 1000uF 电解电容 | 极靠近舵机电源正负极 | 蓄能，防舵机启动瞬间拉死单片机 |
| **继电器模块 5V 输入** | 1000uF 电解电容 | 靠近继电器模块电源脚 | 蓄能，防线圈吸合瞬间电压跌落 |

## 5. ESP32-S3 N16R8 风险引脚与禁用规则

> 优先保证稳定启动与可维护性。

**绝对禁用（本项目外设分配中不得使用）**
1. **GPIO35 / GPIO36 / GPIO37**：N16R8 模组内部（Flash/PSRAM 相关）高风险占用引脚，外设接入会导致启动异常或随机故障。  
2. **GPIO45 / GPIO46**：Strapping/启动高风险引脚，禁止接按键、继电器、传感器等外设负载。  
3. **GPIO0 / GPIO3**：启动模式相关引脚，禁止用于会改变上电电平状态的外设（尤其按键、继电器、强拉高/拉低电路）。

**强烈不建议（仅在无替代引脚且经评审批准后使用）**
- **GPIO19 / GPIO20**：与 USB-JTAG/USB-Serial 调试链路相关，原型调试阶段不建议占用。（注：本项目中 GPIO19 仅分配为输入低有效的楼道报警键；若后续扩展长按复位功能，可接受短时 USB 冲突）。

**预留器件策略**
- **W25Q64 外置 Flash**：三端统一预留焊盘与 CS 位置，当前仅客房端实装；前台/楼控端标注 DNP（预留不装）。
