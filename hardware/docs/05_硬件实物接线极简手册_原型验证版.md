# 硬件实物接线极简手册（杜邦线/原型验证版）

> **致硬件接线与测试工程师：**
> 当前处于**实物原型验证阶段（使用 ESP32 核心板 + 现成模块 + 杜邦线/焊接）**，无需严格按照 PCB 制板标准外挂大量阻容元件。
> 软件底层已开启内部上拉与去抖动，标准模块也已自带基础外围电路。
> 
> **核心接线原则：**
> 1. 除 **MQ-2 烟雾传感器必须外接 2 个电阻进行分压**外，其余标准模块与按键**均可直接连线**。
> 2. 系统由 3 块独立的 ESP32-S3 核心板组成，请严格按照下方各自的清单独立接线。**清单中未提及的引脚直接悬空（NC）即可**。

## 第 1 块板：客房端主控板接线清单

本主控板部署于客房内，外设接入量最大。

### 1. 门禁读卡器 (RC522 模块)
- **SDA (CS)** -> 接 ESP32 的 **GPIO10**
- **SCK** -> 接 ESP32 的 **GPIO12**
- **MOSI** -> 接 ESP32 的 **GPIO11**
- **MISO** -> 接 ESP32 的 **GPIO13**
- **3.3V / GND** -> 接 ESP32 的 3.3V / GND

### 2. 人体雷达 (RD-03 模块)
- **TX** -> 接 ESP32 的 **GPIO16**
- **RX** -> 接 ESP32 的 **GPIO15**
- **3.3V / GND** -> 接 ESP32 的 3.3V / GND

### 3. 强电控制 (4路继电器模块)
- **IN1 (主灯)** -> 接 ESP32 的 **GPIO17**
- **IN2 (插座)** -> 接 ESP32 的 **GPIO18**
- **IN3 (窗帘)** -> 接 ESP32 的 **GPIO31**
- **IN4 (门锁)** -> 接 ESP32 的 **GPIO32**
- **VCC / GND** -> **必须接 5V** / GND

### 4. 语音播报与对讲 (麦克风 + 功放模块)
- **麦克风 (INMP441/LMD2718)**：
  - **SCK** -> 接 ESP32 的 **GPIO42**
  - **WS** -> 接 ESP32 的 **GPIO41**
  - **SD (数据输出)** -> 接 ESP32 的 **GPIO40**
  - **L/R** -> 接 GND (选左声道)
  - **VDD / GND** -> 接 3.3V / GND
- **小功放 (NS4168/MAX98357)**：
  - **BCLK** -> 接 ESP32 的 **GPIO42** (跟麦克风并联)
  - **LRCK** -> 接 ESP32 的 **GPIO41** (跟麦克风并联)
  - **DIN (数据输入)** -> 接 ESP32 的 **GPIO39**
  - **VCC / GND** -> **必须接 5V** / GND

### 5. 屏幕与红外 (OLED + 红外收发)
- **OLED 屏幕 (I2C)**：
  - **SDA** -> 接 ESP32 的 **GPIO21**
  - **SCL** -> 接 ESP32 的 **GPIO8**
- **红外发射管** -> 接 ESP32 的 **GPIO47**
- **红外接收头 (VS1838B)** -> 接 ESP32 的 **GPIO48**

### 6. 物理按键与旋钮 (直接连线，无需外加上拉电阻或去抖电容)
- **呼叫前台按键** -> 一头接 **GPIO14**，另一头接 GND
- **SOS 紧急按键** -> 一头接 **GPIO26**，另一头接 GND
- **场景切换按键** -> 一头接 **GPIO28**，另一头接 GND
- **旋转编码器 (EC11)**：
  - **CLK (A相)** -> 接 **GPIO2**
  - **DT (B相)** -> 接 **GPIO43**
  - **SW (按键)** -> 接 **GPIO44**
  - **+ / GND** -> 接 3.3V / GND

## 第 2 块板：前台端主控板接线清单

本主控板部署于前台桌面，主要负责发卡与房态展示。

### 1. 发卡器 (RC522 模块)
- **SDA (CS)** -> 接 ESP32 的 **GPIO10**
- **SCK** -> 接 ESP32 的 **GPIO12**
- **MOSI** -> 接 ESP32 的 **GPIO11**
- **MISO** -> 接 ESP32 的 **GPIO13**
- **3.3V / GND** -> 接 ESP32 的 3.3V / GND

### 2. 房态展示灯墙 (WS2812B RGB灯带)
- **DIN (数据线)** -> 接 ESP32 的 **GPIO27**
- **5V / GND** -> **必须接 5V** / GND (灯珠较多时建议使用独立 5V 电源，避免开发板供电不足)

### 3. 警报提示 (有源蜂鸣器模块)
- **I/O (控制线)** -> 接 ESP32 的 **GPIO38**
- **VCC / GND** -> 接 3.3V 或 5V / GND

### 4. 物理按键 (直接连线，无需外加上拉电阻或去抖电容)
- **消音/确认按键** -> 一头接 **GPIO29**，另一头接 GND
- **全楼广播按键** -> 一头接 **GPIO30**，另一头接 GND

## 第 3 块板：楼控端主控板接线清单

本主控板部署于走廊，主要负责环境数据采集。

### 1. ⚠️ 关键安全警告：MQ-2 烟雾传感器 (必须加电阻分压)
MQ-2 的 AO 输出为 5V，直接接入 ESP32 会导致引脚烧毁！必须使用两个电阻（如 1K 和 2K）进行降压：
- **MQ-2 的 AO 脚** -> 连 **1K 电阻**的一头
- **1K 电阻**的另一头 -> 连 **2K 电阻**的一头，**并将 ESP32 的 GPIO4 接入此连接点**
- **2K 电阻**的另一头 -> 连 **GND**
- **MQ-2 的 VCC / GND** -> **必须接 5V** / GND

### 2. 其他环境传感器 (直接连线)
- **光敏电阻模块** -> AO 接 ESP32 的 **GPIO5**
- **热敏电阻(NTC)模块** -> AO 接 ESP32 的 **GPIO6**
- **电位器模块** -> AO 接 ESP32 的 **GPIO7**

### 3. 走廊照明与按键
- **走廊灯继电器** -> 控制线接 **GPIO17**，电源接 5V / GND
- **楼道报警按键** -> 一头接 **GPIO19**，另一头接 GND (无需外加电阻电容)

---

### 💡 调试排障建议：遇到死机/重启怎么办？
如果在测试过程中，发现**继电器吸合**或**功放发声**的瞬间，ESP32 发生重启或死机，通常是因为瞬态电流过大导致电压跌落。
**解决方案**：找一个较大容量的电解电容（如 1000uF），直接并联插在面包板的 5V 和 GND 轨道上进行稳压即可。若测试稳定未死机，则无需添加。
