# 智慧酒店物联网控制系统 - 硬件制图与实施交付手册（集成打板版）v1.0

> **文档定位**：本手册用于后续正式 PCB 打板与集成制图阶段的统一依据。
> 采用“全终端一体化 Pinmap”呈现方式，便于在同一份工程基线中统一核对引脚冻结、被动件落点与电源域要求。

## 5. ESP32-S3 N16R8 风险引脚与禁用规则

> 优先保证稳定启动与可维护性。

**绝对禁用（本项目外设分配中不得使用）**
1. **GPIO35 / GPIO36 / GPIO37**：N16R8 模组内部（Flash/PSRAM 相关）高风险占用引脚，外设接入会导致启动异常或随机故障。  
2. **GPIO45 / GPIO46**：Strapping/启动高风险引脚，禁止接按键、继电器、传感器等外设负载。  
3. **GPIO0 / GPIO3**：启动模式相关引脚，禁止用于会改变上电电平状态的外设（尤其按键、继电器、强拉高/拉低电路）。

**强烈不建议（仅在无替代引脚且经评审批准后使用）**
- **GPIO19 / GPIO20**：与 USB-JTAG/USB-Serial 调试链路相关，原型调试阶段不建议占用。（注：本项目中 GPIO19 仅分配为输入低有效的楼道报警键；若后续扩展长按复位功能，可接受短时 USB 冲突）。

**预留器件策略**
- **W25Q64 外置 Flash**：三端统一预留焊盘与 CS 位置，当前仅客房端实装；前台/楼控端标注 DNP（预留不装）。
