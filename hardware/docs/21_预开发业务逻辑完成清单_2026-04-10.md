## 1. 已完成（可联调）

### 1.1 客房端（room_terminal）

- 已完成基础执行命令：`light_on/off`、`air_on/off`、`curtain_open/close`、`door_unlock/lock`。
- 已完成场景模式命令：`scene_welcome`、`scene_reading`、`scene_night`、`scene_sleep`、`scene_next`。
- 已完成本地按键业务：
  - `BTN_ROOM_SCENE`：本地轮转场景。
  - `BTN_ROOM_SOS`：上报 `room_sos_pressed` 安防事件。
- 已完成门锁自动回锁预开发逻辑：
  - 开锁后自动进入回锁计时（默认 8 秒）。
  - 到时自动执行 `door_lock`，并上报 `door_auto_locked` 事件。
  - 自动回锁回执新增 `result_code=door_lock_auto`，与手动锁门可区分。
- 已完成运行态上报：灯光/空调/窗帘/门锁/通话态等状态字段。

### 1.2 前台端（front_desk_terminal）

- 已完成前台按键业务：
  - `BTN_FRONT_CLEAR`：下发 `hangup_call`。
  - `BTN_FRONT_BROADCAST`：下发 `incoming_call`。
- 已完成房卡业务预开发：
  - `issue_card`：写卡流程（预开发阶段支持 mock 卡缓冲）。
  - `verify_card` / `swipe_card`：验卡流程。
- 已完成验卡联动开锁：
  - 验卡成功后自动下发 `door_unlock` 至目标客房。
- 已完成回执发布与订阅处理：
  - 前台业务指令回执发布到 `hotel/device/command/result`。
  - 订阅并打印执行回执日志。

### 1.3 楼控端（floor_controller）

- 已完成基础命令：`light_on`、`light_off`。
- 已完成楼道报警按键事件上报：`floor_alarm_pressed`。
- 已完成运行态上报与命令回执链路。
- 已完成占位命令入口：`broadcast_start`、`broadcast_stop`、`floor_reset`（为后续真外设联调保留）。

### 1.4 公共组件与协议层

- 已完成 MQTT 服务主链路（连接、订阅、发布、重连恢复订阅）。
- 已完成全局主题与预开发开关配置（`global_config.h`）：
  - Topic 前缀统一宏。
  - `GLOBAL_ENABLE_MOCK_*` 开关。
- 已完成三端 `main.c` 主题硬编码收敛（状态/数据/命令/回执/安防统一走全局宏）。
- 已完成后端下发主题兼容优化（按设备类型下发）。
- 已完成安防事件字段兼容（后端同时兼容 `event_data` 与 `data`）。

## 3. 当前可验证的业务闭环（联调态）

1. 前台发卡 -> 刷卡验证 -> 自动下发客房开锁。  
2. 客房接收开锁 -> 到时自动回锁 -> 状态/事件上报。  
3. 客房场景切换（云端命令 + 本地按键）-> 状态回传。  
4. 楼控灯控命令 -> 执行回执 -> 运行态上报。  
5. 前台广播/消警按键 -> 客房通话状态命令链路。
