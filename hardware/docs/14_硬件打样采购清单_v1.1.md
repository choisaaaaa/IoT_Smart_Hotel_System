## 💰 单客房硬件造价预估概念 (Single Room Cost Concept)

在向评委或导师进行项目商业概念汇报时，可参考以下“单客房核心物料成本预估”：

- **核心运算与通信**：ESP32-S3 (约 25 元)
- **环境与人体感知**：DHT11 + MQ-2 + 光敏 + NTC + RD-03 雷达 (约 31 元)
- **执行与门禁控制**：4路继电器 + 舵机 + RC522 (约 26 元)
- **AI 语音与交互**：LMD2718 + NS4168 + 喇叭 + EC11 + 按键 (约 31.5 元)
- **状态提示与存储**：OLED + RGB + 蜂鸣器 + W25Q64 (约 15 元)

> **结论**：本套采用全分布式的“WiFi直连+边缘计算”方案，单间客房在**不包含阻燃外壳与 PCB 制板费**的前提下，**核心物料 BOM 成本压缩在 130 元以内**。对比传统酒店动辄千元的 RCU 客房控制箱，具备极强的低成本下沉市场（快捷酒店/民宿）落地竞争力。
